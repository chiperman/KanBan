# Landing 图标来源

所有图标随静态站点本地提供，页面不请求外部图标服务。品牌图标通过 CSS mask 使用同一灰色，不修改原始文件。

| 文件                                                                                  | 来源                                                                                                                   |
| ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `nodedotjs.svg`、`pnpm.svg`、`binance.svg`、`okx.svg`、`ethereum.svg`、`bnbchain.svg` | [Simple Icons 16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0/icons)，CC0-1.0，许可见同目录 `LICENSE` |
| `longbridge.png`                                                                      | 长桥官网引用的 [官方图标](https://assets.wbrks.com/assets/logo/logo1.png)                                              |

Bitget、BIT / Matrixport、手工资产使用页面内的通用交易、账户和账本线形图标，不作为对应平台的品牌标识。品牌及商标归各自权利人所有，展示不表示合作或背书。

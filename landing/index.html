再了解一点。

这个页面能直接查看我的资产吗？

这里是独立的产品介绍页，演示全部使用固定虚构数据，不会连接你的账户。先在自己的设备启动 KanBan，再通过本机服务登录并接入资产来源。

KanBan 会替我交易吗？

不会。KanBan 用于只读查看与记录，不提供下单、转账、调仓或自动投资入口。请在账户供应商处授予只读权限，不授予交易或提现权限。

数据会发送到哪里？

资产与账目数据保存在运行 KanBan 的本机。同步时会请求你配置的账户供应商、行情或链上服务；KanBan 不提供集中归集个人资产数据的云端服务。你仍需妥善保护运行设备、凭证与备份。

支持哪些系统？可以持续在后台运行吗？

当前验证基线为 macOS Apple Silicon。可准备独立的生产运行副本和数据目录，通过 macOS 后台任务持续采集；具体命令与迁移边界见仓库文档。Windows 和 Linux 尚未完成验收。

能添加第三方插件吗？

官方版本仅提供随应用构建的官方接入，不提供插件商城、导入或运行时下载安装。新接入通过源码 PR 审核后随应用提供；自定义开发请在自己的 Fork 和隔离环境中进行。

04 / GET STARTED

在自己的机器上，
跑起来。

KanBan 目前面向本地运行。首次启动需要 Node.js、pnpm 与 Rust；当前验收基线是 macOS arm64。

NODE 24.15.0 PNPM 11.25.0 RUST
打开 GitHub 仓库
TERMINAL / SETUP 
$ git clone https://github.com/chiperman/KanBan.git
$ cd KanBan
$ pnpm install --frozen-lockfile
$ pnpm native:longbridge:build
$ pnpm dev
THEN

打开 http://localhost:3000/setup 预置 Passkey，之后从 / 查看资产。

06 / QUESTIONS

开始之前。

KanBan 会进行自动交易吗？

不会。KanBan 是纯粹的只读看板，不提供任何下单、转账或调仓功能。所有 API 凭证仅用于读取资产与同步快照。

数据会上传到云端吗？

所有资产与账目数据仅保存在你的本机。应用仅在拉取公开行情或查询链上状态时直连对应节点，绝无中心化服务器归集你的个人数据。

为什么采用 Passkey 登录？

KanBan 为单一所有者专属设计，不设公开注册。首次启动时即与你的硬件 Passkey 绑定，兼顾生物识别的便捷与高强度本地安全，亦支持 TOTP 备用认证。

目前支持哪些操作系统？

官方验证并推荐 macOS (Apple Silicon)。Windows 与 Linux 开发者可基于开源源码自行构建与适配。

可以直接在网页端使用完整功能吗？

不能。当前静态网页仅作产品展示。完整的看板服务运行在本地，由本地 SQLite 与加密环境守护你的全部资产凭证。

本地部署

KanBan 面向本地运行。首次启动需要 Node.js、pnpm 与 Rust；当前验收基线是 macOS arm64。

NODE 24.15.0 PNPM 11.25.0 RUST
打开 GitHub 仓库
启动命令 
$ git clone https://github.com/chiperman/KanBan.git
$ cd KanBan
$ pnpm install --frozen-lockfile
$ pnpm native:longbridge:build
$ pnpm dev

打开 http://localhost:3000/setup 预置 Passkey，之后从 / 查看资产。

常见问题

KanBan 会进行自动交易吗？

不会。KanBan 是纯粹的只读看板，不提供任何下单、转账或调仓功能。所有 API 凭证仅用于读取资产与同步快照。

数据会上传到云端吗？

资产与账目数据保存在运行 KanBan 的本机。同步时会请求你配置的账户供应商、行情或链上服务；KanBan 不提供集中归集个人数据的云端服务。

为什么采用 Passkey 登录？

首次启动在 /setup 注册所有者 Passkey，之后使用设备或密码管理器中的 Passkey 登录。可配置 TOTP 备用登录，没有公开注册入口。

目前支持哪些操作系统？

官方验证并推荐 macOS (Apple Silicon)。Windows 与 Linux 开发者可基于开源源码自行构建与适配。

这个网页可以直接查看我的资产吗？

当前网页仅作产品展示，图中的数据是虚构示例。先在本机启动 KanBan 服务，再通过浏览器访问本地地址，即可登录并接入自己的资产来源。

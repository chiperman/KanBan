# 01 · 基础规范（Foundations）

所有值来自 `src/app/design-tokens.css`。本文件中的每个数值都可以在 `styleguide.html` 的对应章节里实时核对。

---

## 1. 色彩

暗色优先。灰阶本身承担层级，一屏灰色不超过 4 种。文字使用柔白／柔黑而非纯 `#FFF` / `#000`，以降低眩光。

### 1.1 画布与表面

| Token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `--bg` | `#000000` | `#f2f2f2` | 页面画布（OLED 黑 / 暖灰纸） |
| `--surface` | `#0c0c0c` | `#ffffff` | 菜单、弹层、对话框底色 |
| `--raised` | `#171717` | `#ededed` | 次级抬升、悬停行、缩略图与键帽填充 |
| `--overlay` | `rgba(0,0,0,.88)` | `rgba(242,242,242,.9)` | 模态遮罩 |
| `--glass` | `rgba(16,16,16,.9)` | `rgba(255,255,255,.96)` | 玻璃卡填充，必须与 `backdrop-filter` 成对使用 |
| `--glass-brd` | `rgba(255,255,255,.09)` | `rgba(0,0,0,.08)` | 玻璃卡可选的内侧 1px 细线 |

### 1.2 文本层级

| Token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `--display` | `#ffffff` | `#000000` | 标题、主数字、反转填充 |
| `--primary` | `#ededed` | `#1c1c1c` | 正文与默认图标色 |
| `--secondary` | `#8c8c8c` | `#585a5a` | 标签、次级说明 |
| `--muted` | `#5a5a5a` | `#9a9a9a` | 最弱文字、占位符、刻度 |

### 1.3 线条

| Token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `--line` | `#262626` | `#e2e2e2` | 列表、表格、分区之间的分隔细线 |
| `--line-2` | `#3a3a3a` | `#cfcfcf` | 控件轮廓、可见边框、分段条空槽 |

细线恒为 1px。**不要把细线加粗来强调**——需要强调时增加留白，或改用反转填充。

### 1.4 信号

| Token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `--accent` | `#d71921` | `#d71921` | 信号红**填充**：需要决策、越限、录制/实时点、通知角标 |
| `--accent-text` | `#ff4438` | `#c2141c` | 强调色作为**前景**（文字/边框/图标），暗色提亮、亮色压深以保对比 |
| `--accent-ink` | `#ffffff` | `#ffffff` | 红底之上的文字色 |
| `--restricted-dot` | `rgba(255,255,255,.12)` | `rgba(0,0,0,.14)` | 受限内容的点阵纹理，**不承载金额语义** |
| `--dotbg` | `rgba(255,255,255,.48)` | `rgba(0,0,0,.42)` | 上游遗留 token，当前点场不使用 |

**强调色规则（不可协商）**

1. 强调色只用于真实信号：需要决策的计数、`NEEDS INPUT`、越限数值、实时点、通知角标、语义告警，以及强调色色板本身。
2. 典型一屏 **0–2 个红色元素**。判断标准很直接：如果去掉这个红色之后界面没有任何信息损失，那它就是装饰，不该存在。
3. **填充与前景是两枚 token**。红底白字用 `--accent` + `--accent-ink`；红字/红边/红图标用 `--accent-text`。不得把填充红直接当文字色使用。
4. 强调色绝不用于：按钮、标签页、链接、滑块、悬停态、选中芯片、开关 ON。

### 1.5 数据状态

| Token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `--success` | `#7be38a` | `#3d8b4a` | 正常、已连接、已刷新 |
| `--warning` | `#f2c94c` | `#9c6b00` | 注意、待确认 |
| `--error` | `#ff5247` | `#d23b30` | 错误；与强调色同属一个红色家族 |

状态色**只落在数值本身**，不落在标签、表头或整行背景上。亮色主题下三种状态色都压深以满足对比度。

### 1.6 兼容别名

`--black` `--dark-grey` `--grey` `--light-grey` `--white` 是上游早期命名的中性色别名（`design-tokens.css:58–62`），仅供历史样式引用。**新代码不得使用**，请改用上表的分层 token。

## 2. 字体排版

五种角色，各有其职。层级由字号跳变与角色区分承担，**不靠字重与颜色堆叠**。

| 角色 | Token | 家族 | 用途 |
|---|---|---|---|
| 点阵显示 | `--f-display` | Doto | 字标、主数字、独字数字与其百分号、时钟、模块编号 |
| 界面/正文 | `--f-ui` | Geist | 正文、说明文字 |
| 等宽/数据 | `--f-mono` | Geist Mono | 大写标签、数据、代码、表格单元格、时间戳 |
| 标题 | `--f-head` | Geist（600） | 卡片标题、对话框标题、分区标题 |
| 编辑体强调 | `--f-editorial` | Newsreader Italic | 仅页面级的一句品牌文案或引语 |

### 2.1 强制规则

- **Doto 字重上限 500**，且必须保留 `font-variation-settings: "ROND" 100`。加粗会让相邻圆点粘连、曲线顶端出现尖角（数字 `0` 会长出尖顶）。
- **编辑体斜体的边界是页面级 vs 组件级**：它只允许出现在页面级文案（一句 hero、一句引言，一屏至多一句），**绝不出现在任何可复用组件内部**——按钮、输入框、卡片、表格、导航、弹窗、标签、列表、看板磁贴一律无衬线。
- 标签一律 `--f-mono` + 全大写 + 字距 `.08–.14em`。
- 金融数值使用 `font-variant-numeric: tabular-nums` 保证跨行对齐。
- 中文正文由 `--f-ui` 自动回退到 `PingFang SC` → `Noto Sans SC` → 系统无衬线，这是本产品的适配层规则，不改变上游视觉契约。

### 2.2 排版级差

字号分**两族**，不要互相替代。给正文用展示档会让字号突然跳档，给大数字用正文档会让它淹没在页面里。

**文字族**（排句子与标签，步长密集）

| Token | 值 | 真实用途 |
|---|---|---|
| `--vibe-type-heading` | 24px | 卡片标题、分区标题 |
| `--vibe-type-subheading` | 18px | 小节标题、对话框标题、来源标题 |
| `--vibe-type-title` | 20px | 小标题与仪表数字共用的一档：身份名、锁定时钟、验证码格、趋势区间数字 |
| `--vibe-type-body` | 16px | 输入控件、说明正文 |
| `--vibe-type-body-sm` | 14px | 次级正文 |
| `--vibe-type-body-xs` | 13px | **产品的正文基准**——`body` 元素本身用的就是这一档；对话框正文、下拉触发器、日历格、次级按钮文字、空态提示同属这一层 |
| `--vibe-type-caption` | 12px | 注释、时间戳、次级说明 |
| `--vibe-type-label` | 11px | 等宽大写标签、表格表头、单位 |
| `--vibe-type-micro` | 10px | 最小一档的等宽大写微标签：字段标签、眉标、快捷键提示 |

**展示族**（排"一屏一个的大数字"）

| Token | 值 | 真实用途 |
|---|---|---|
| `--vibe-type-display-xl` | 72px | 登录展示态的大字标 |
| `--vibe-type-display-lg` | 48px | 总览金额、登录门标题 |
| `--vibe-type-display-md` | 36px | 当日变动金额 |
| `--vibe-type-display-sm` | 26px | 趋势卡里的昨日／区间数字 |

> **为什么 13 与 20 这两档非补不可**：产品的 `body` 就是 13px，而级差表原本最低到 11px——**规范解释不了产品自己的正文**，这是缺档而不是代码写错。20px 更直接：`--vibe-type-title` 这个 token 早就被 `.trend-interval-change > strong` 等处引用了，只是从未定义，浏览器一直静默丢弃那些声明（见 D-21）。

> **与上游的差异（已声明）**：上游站点使用的标题序列是 40 / 32 / 24 / 20 / 16 / 14 / 11。本产品按 `DESIGN.md` 第 2 节，只用这一组 4px 基准的排版级差 token，不额外引入第二套字号语言。两套序列不混用。

> **取值收敛（D-18 已整改）**：本表每一档都有真实使用点，产品里在用的每一个字号取值也都在表内。此前脱节的部分共 76 处——10px 档缺失（40 处散落为 `9px` / `10px`），`13` / `15` / `17` / `19` / `20` / `22` / `26` / `42` / `44` / `52` / `68` 共 36 处落在表外。`15` / `17` / `19` / `22` / `42` / `44` / `52` / `68` 按"就近吸附"并入相邻档位，其余按"补档"新增。判据与逐条记录见 [`07-deviation-register.md`](07-deviation-register.md) D-18。

> **两处按设计豁免**：`.locked-flow-screen text`（9px）与 `.locked-flow-dashboard-label`（8px）位于 `owner-login.tsx` 的 `<svg>` 内部。那里是 SVG 用户坐标系，`px` 是图纸单位、会随 `viewBox` 缩放，**排版级差不适用于它**。这两条写在守门脚本的 `SVG_TEXT_SELECTORS` 里，不占基线条目。

## 3. 间距

基准 4px。只使用下表档位，不写任意 px 值。

| Token | 值 | 关系语义 |
|---|---|---|
| `--vibe-space-0` | 2px | —（见下方注解） |
| `--vibe-space-1` | 4px | 触碰级（图标与文字之间） |
| `--vibe-space-2` | 8px | 同组内 |
| `--vibe-space-3` | 12px | 同组内上限 |
| `--vibe-space-4` | 16px | 组件内边距 |
| `--vibe-space-5` | 20px | 面板内边距 |
| `--vibe-space-6` | 24px | 模块内边距 |
| `--vibe-space-8` | 32px | 新分组 |
| `--vibe-space-10` | 40px | 新分组 |
| `--vibe-space-12` | 48px | 新语境 |
| `--vibe-space-16` | 64px | 新语境 |
| `--vibe-space-24` | 96px | 页面级留白 |

> `--vibe-space-0` 为 2px，不是 4px 的倍数。它与 `DESIGN.md` 第 2 节「`--vibe-*` 仅限已记录的 4px 布局/字号刻度」的表述冲突，已登记在 [`07-deviation-register.md`](07-deviation-register.md)。在治理层给出结论前，**新代码不要使用 `--vibe-space-0`**。

**当你伸手去拿一根分隔线时，通常真正需要的是更多留白。**

## 4. 圆角

| Token | 值 | 适用 |
|---|---|---|
| `--r-sm` | 6px | 控件、按钮、输入框、状态标签 |
| `--r-md` | 8px | 卡片、对话框、面板 |
| `--r-pill` | 999px | 芯片、开关轨道、头像 |

**卡片圆角不得超过 8px，也不得使用大胶囊。** 圆角不是表达层级的工具——层级由细线与留白建立。

## 5. 层次

系统**没有阴影**。深度只由 z-index 与细线表达。

| 层 | z-index | 用于 |
|---|---|---|
| base | 10 | 常规内容 |
| overlay | 30 | 下拉菜单、下拉选项面板 |
| modal | 40 | 对话框 |
| header | 50 | 吸顶页头 |
| floating | 80–120 | 提示浮层及浮动变体 |

例外说明：玻璃卡的 `backdrop-filter: blur()` 是**材质**，不是阴影。它表达"这是一层玻璃"，而不是"这层浮在上面"。

## 6. 动效

| 场景 | 值 | 说明 |
|---|---|---|
| 微交互 | `200ms` · `ease-in-out` | 控件、边框、透明度 |
| 主题切换 | `350ms` · `ease-in-out` | 仅颜色与背景 |
| 悬停 | `opacity .8`（按钮） / `translateY(-2px)`（卡片） | 禁止改色，禁止加阴影 |
| 按下 | `opacity .6` | 机械、干脆 |
| 禁用 | `opacity .3` | 特殊进行态可局部放宽（如刷新中为 `.68`） |

缓动只有 `ease-in-out`。**没有弹簧、没有回弹、没有缩放弹出、没有视差。** 动效优先使用透明度，位移要克制。

数据类动效（如计数滚动）统一为 1200ms 三次缓动，滚动进入视口后才启动，并遵守减弱动效偏好。

## 7. 控件尺寸

| Token | 值 | 说明 |
|---|---|---|
| `--vibe-control-height-compact` | 40px | 紧凑控件（菜单触发器、菜单项） |
| `--vibe-control-height` | 44px | 标准控件（按钮、输入框、下拉） |
| `--vibe-control-padding-inline` | `var(--vibe-space-4)` = 16px | 水平内边距 |

可见轮廓可以很薄（状态标签只有 24px 高），但**交互命中区不得低于 40px**，详见 [`05-accessibility.md`](05-accessibility.md)。

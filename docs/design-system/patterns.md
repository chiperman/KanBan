# 页面模式：布局、信息与验收

本文维护页面组合与信息呈现。页面职责和路由以 [当前能力与源码导航](../current-baseline.md) 为准，组件接口见 [组件规范](components.md)，采用契约见 [DESIGN](../../DESIGN.md)。

## 页面骨架

实现入口为 [WorkbenchShell](../../src/ui/workbench-shell.tsx) 与 [workbench.css](../../src/app/product-layout/workbench.css)。产品样式由 [product-layout.css](../../src/app/product-layout.css) 按顺序加载，后续覆盖层保持原有先后关系。侧栏、页头与内容区通过细线和留白分隔，不用阴影强调层级。

- 桌面主导航为总览、资产、投资账本，设置位于侧栏底部；手机底栏显示四项。
- 侧栏宽度由 `--workbench-rail-width` 与展开状态共同决定；折叠状态沿用工作台实现，内容留白与导轨同步，不把展开宽度写死到各页。
- 页头不添加眉标、标语或重复页标题的说明。必要的连接状态保留为状态。
- 页头承载标题与页面操作，采用细线分区，不包装成数据卡片。窄屏操作区允许换行。
- 当前页用 `aria-current="page"` 与中性交互底色或文字层级表达，不使用强调色。
- 主题跟随现有明暗及系统偏好能力；不能以历史“工作台固定暗色”的描述覆盖当前选择。
- 窄屏顶部的隐私、搜索、主题与锁定工具统一为 44×44px，复用 20px 图标并居中对齐。品牌与工具组空间不足时自然换行，工具整组靠后对齐；200% 文字下仍保留完整名称、命中范围与操作顺序，不裁切锁定入口。

## 响应式

| 档位 | 组合规则 |
| --- | --- |
| ≥1200px | 显示桌面侧栏，内容为导轨留出空间 |
| <1200px | 隐藏桌面导航，使用底部移动导航；内容取消导轨留白，并预留导航高度、操作空间与安全区 |
| 640–1023px | 需要栅格的页面降为两列，跨列内容相应降级 |
| <640px | 单列为主，操作可占满整行，页内边距收为 16px；对话框按组件配方贴底或全屏 |

新增样式使用 0 / 640 / 1024 / 1200 四档边界；已有其他断点需按实际布局核定，统一见 [backlog](../backlog.md#存量样式与守门基线收敛)。不能只改数值而跳过受影响页面的组合关系。

移动导航高度由 `--workbench-mobile-navigation-height` 推导；底部留白计入 `env(safe-area-inset-bottom)`，确保内容和操作可滚动到末尾。

## 卡片与内容组合

按页面的信息关系决定栅格，不为了填满版面制造卡片。使用栅格时按宽度降为三列、两列或单列；同行需要对齐的卡片可等高，操作区由容器布局贴底，不依赖已移除的旧选择器。

通用 `.card` 使用 `--surface`、0.5px `--line` 与 `--r-md`，用于确有独立边界的内容。首页总资产与走势共用主面板，三本账各用独立面板，不嵌套玻璃卡片。认证表面的合同由组件规范维护。

卡片不以悬停增加阴影。布局编辑若提供拖拽或缩放，需有非拖拽的等价操作；状态标记遵守 [项目适配](../../DESIGN.md#项目适配)。空态结构见 [组件规范](components.md#空态)，无内容时不堆占位卡片。

## 首页总览

- 页头集中标题与计价、刷新操作，窄屏操作换行；资产摘要直接置于其下，不再以额外分隔线拆成两个页头。总资产为首要读数，资产变化与比较日期为次要读数；异常摘要紧邻总额，可展开查看影响及检查入口。
- 总额旁的资产同步时间取已记录来源的实际快照时间；不同来源显示最早至最新的时间范围，不以页面生成时间或实时行情时间替代。未记录金额的手工来源不参与，时间缺失或无效时显示未知。
- 同步失败的来源、最近成功数据与恢复操作并入现有异常摘要。整批结果与单来源结果分开，成功来源不继承整批失败；重试仅针对可重试的失败来源，授权问题进入对应连接设置，未知原因进入来源管理，不根据报错文字猜测。
- 总额、今日变化与走势共用主面板，走势保留共享区间、自定义日期与缺失状态。≥1200px 主面板在左、三本账在右纵向排列，两列上下边缘对齐，右侧卡片等分高度并随内容自然增高；640–1199px 账本在主面板下方横排，手机依次纵排。来源分布始终位于其下，来源名称直接进入详情，不重复放置明细按钮。
- 来源同时显示当前金额、变化和前值，≥1024px 共用列宽对齐，更窄时每项分两行。比较日期取实际上一条完整记录，不得把跨日的完整记录写成“昨日”。健康状态不逐行重复，异常状态保留。
- 三本投资账沿用独立面板，名称、资产金额、累计净投入、累计收益与记录日期顺序展示；沿用各自币种，不混入总资产的计价选择。
- 未接入来源时只显示新增入口，不重复堆叠走势、来源、账本的缺数据占位。金额隐藏与数据质量规则沿用金融信息合同。

## 来源连接与管理

实现入口为 [AssetSourceDetail](../../src/ui/asset-source-detail.tsx) 和 [LongbridgeConnectionSummary](../../src/ui/longbridge-connection-settings.tsx)。

- 「资产概况 / 连接与管理」等宽同行；桌面保持紧凑，<1024px 占满内容区，切换选中态时尺寸稳定。
- 页头计价货币与刷新（手工来源为更新资产）等宽同行、底部对齐；<1024px 操作区占满内容宽度。
- 使用一个连续的设置面板，顺序为基本信息、连接与授权、危险操作；不并排放置内容长度悬殊的卡片，也不拉高空白区域对齐。
- ≥1024px 每节按“标题 / 内容”两栏对齐；更窄时标题位于内容上方，<640px 字段标签与值、表单按钮、行操作继续纵向排列。内容和错误文字自然换行，无固定高度。
- 基本信息保留来源类型与名称编辑，不重复展示当前名称。来源标识默认折叠；手工来源在此维护资产类别，不出现连接与授权区。名称、类别与观察钱包资产范围共用设置保存边界，仅在明确收到无错误字段的 `{ok:true}` 后反馈成功，页面重读期间保持等待状态。保存最多等待 30 秒，包含响应正文；会话失效与服务端异常在读取正文前判定，离开页面后不处理旧请求结果。
- 设置保存期间防重复提交，失败保留输入和显示状态；明确拒绝允许修正后重试，网络中断、超时、服务端异常或无效成功响应暂停重传。结果不明时提供已有设置页的新标签页核对入口，确认未保存后由用户恢复操作，不自动重试，不把页面重读当作本次写入成功。
- 名称与类别共用草稿同步规则：未编辑时跟随页面重读的服务端值，已编辑时保留输入并与最新已保存值比较；重读不把旧显示值变成待保存修改。保存完成后确认提交值，请求期间已收到新值时不以旧请求覆盖；切换来源重新初始化草稿。
- 连接与授权常驻账户、连接方式、只读权限及最近同步尝试时间；长桥版本、授权通道与最近读取方式放入“连接详情”。其他自动来源保留重新授权入口，观察钱包提供公开地址与资产范围入口。
- 来源生命周期、同步结果与通道检测分别表达，颜色遵守 [状态映射](components.md#状态映射)。“已连接（只读）”用绿色表达已建立连接；实时通道在检测通过前保持“正在验证”等中性状态，最近同步尝试不能标成成功校验。同步失败、检测失败与账户不一致直接显示，不藏在折叠详情中。
- 同步故障复用统一的原因、状态与恢复判断。实时行情故障提供重试及来源连接设置入口；CLI 登录问题与 SDK 资产授权分开，不跳转无关的行情或链上服务配置。长桥连接与 CLI 检测最多等待一分钟，失败或超时保留同一来源的上次结果和检测时间，明确标记旧结果，不能用于放行接入；身份失效或来源不可访问时清除旧结果。
- 长桥完整连接与 CLI 检测在共享读取边界校验响应结构；缺失字段或无效授权状态按读取失败处理，不替换上次有效结果。重新检测、切换来源或离开页面时取消已失效的读取，迟到结果不覆盖当前状态。
- CLI 登录使用原生表单，输入授权码后可按 Enter 提交，与按钮共用校验和互斥。最多等待一分钟，时限包含响应内容读取，仅将明确的 `{ok:true}` 视为服务端已完成请求；提交后清除一次性授权码，不自动重传。明确完成或结果不明后只读核对当前 CLI 授权及账户，不能把状态读取写成“本次登录成功”；核对失败时暂停再次登录及需要 CLI 的接入，保留重新检测入口。CLI 登录提示只在包含 CLI 的方式下显示，不干扰独立可用的 SDK；切回 CLI 仍须完成核对，切换来源或离开后不再处理旧登录结果。
- 不提供旧总览卡片隐藏或恢复显示入口，历史布局数据仍保留；断开、恢复及永久删除位于明确的危险操作区，使用共享按钮与既有确认流程。业务后果以 [CONTEXT](../../CONTEXT.md) 为准。
- 来源设置、断开、恢复、永久删除与手工记录删除共用来源写请求边界，最多等待 30 秒，包含响应正文；会话失效与服务端异常先于正文判定。危险操作在请求与页面重读期间互斥，仅在明确收到无错误字段的 `{ok:true}` 后关闭确认框并更新页面；永久删除成功返回设置中的来源列表，离开来源后不处理旧请求结果。
- 危险操作明确拒绝时保留确认框并允许重试；网络中断、超时、服务端异常或无效成功响应时暂停重传，提供新标签页核对入口。断开与恢复核对来源状态，永久删除核对来源列表，手工记录删除核对该日记录；核对不作为本次操作成功的证明。关闭弹窗或切换概况与管理不解除核对要求；原操作禁用时，关闭弹窗后将焦点交给核对入口。确认尚未执行后由用户重新发起；断开重走确认，永久删除重走两次确认。
- 永久删除的两步共用弹窗容器，步骤切换更换确认按钮；双击或按键连发不能跨过第二次确认，常规取消后焦点回到删除入口。

## 数据与维护及来源入口

- 数据与维护复用来源设置的连续面板结构，按“资产来源 / 自动采集与日结 / 数据检查 / 行情与链上服务 / 备份与恢复”纵向排列；≥1024px 标题与内容两栏对齐，更窄时改为上下排列，不按卡片等高或保留空白。
- 采集记录、来源采集明细和规则默认折叠；来源采集有错误时展开记录。数据检查常驻同步与估值摘要，异常按原因聚合并链接到来源；历史覆盖保留筛选与分页，不把历史缺口解释成当前同步失败。
- 来源管理集中在设置的“数据与维护”，列表包含无持仓、手工无记录、总览已隐藏和已断开的来源，只展示名称和必要状态，不重复来源总额。设置中的来源名称直达“连接与管理”，资产阅读入口继续进入概况。偏好、安全和数据与维护各自只读取当前分类所需的数据。
- 新增来源完成、取消及来源删除后返回设置中的资产来源列表，手工无记录来源可直接进入详情继续记录。旧来源列表链接兼容跳转到同一位置；备份恢复、授权确认和危险操作沿用既有流程。
- 来源详情不展示“每日总额”折叠列表；按日资产金额与资金明细在投资账本的“记账记录”中查看。重新授权取消或成功后返回该来源的“连接与管理”（`/asset-sources/[id]?view=manage`）。
- 接入验证、授权回调预览读取、保存与取消互斥；网络异常后释放操作锁并保留可用结果。来源确认每项最多等待 30 秒；超时、服务端异常、成功响应不完整或预览正在确认时先核对来源，暂停再次保存及取消。预览失效提供重新验证入口，已清除的凭证不恢复，10 分钟有效期不变。
- 来源确认保留读取范围，展示已验证的账户名称与必要标识；多链确认逐项保留成功来源，明确已保存及待完成项，重试只处理剩余项，取消不回滚已保存来源。
- 行情与链上服务保存期间禁用相关输入，最多等待 30 秒，失败保留输入；超时、服务端异常或成功响应不完整时先重读状态再决定是否重新保存，不把状态读取当作密钥内容校验。只读核对最多等待 15 秒，超时保留输入和上次状态并允许重试；写入不自动重试。服务验证时间按上海时间展示。
- 行情与链上服务的状态读取及保存响应在同一请求边界校验三个服务的配置状态与验证时间；保存仅在三个服务均已配置且验证时间有效时确认。无效响应不替换上次状态、不清空输入；明确拒绝允许修正重试，结果不明时保留核对入口。会话失效及保存的服务端异常在读取正文前判定。
- 安全设置的请求与响应校验由同一边界负责：Passkey 绑定准备、配置状态读取及 TOTP 密钥生成与核对最多等待 15 秒；Passkey 绑定确认、移除及 TOTP 保存最多等待 30 秒，均包含响应正文，不覆盖设备 WebAuthn 流程自身的等待。写入仅接受无错误字段的 `{ok:true}`，服务端异常先于正文判定；无效响应不覆盖上次状态，不将非字符串错误直接显示到界面。
- Passkey 绑定区分设备流程取消或超时、连接中断与服务端拒绝；移除请求中防误关，失败留在确认框，超时后释放等待并提供状态核对。写入结果不明时先读取当前配置状态，不自动重试，也不将状态读取当作本次绑定成功；仍沿用单 Passkey 替换与 TOTP 保护。
- TOTP 配置在生成与保存期间防重复操作和误关，失败释放等待状态并保留可用密钥及输入。结果不明时暂停保存，通过已登录、同源的只读请求核对本次密钥是否与已存密钥一致，不回传已存密钥、不消费验证码，也不凭“已配置”认定新密钥生效。核对失败可重试，明确不一致后才恢复保存；“稍后核对”关闭再打开保留本次密钥与验证码，普通取消或成功后清空草稿，不将草稿持久化。配置成功立即同步 Passkey 移除条件，再次打开不丢失已配置状态。
- TOTP 密钥生成、填写与核对共用一个弹窗，关闭后焦点回到配置入口；各阶段主操作保持独立身份，核对不一致只恢复编辑，不触发保存。
- 观察钱包关注或忽略成功后局部更新；原生币忽略确认在请求中保留，明确拒绝允许就地重试，结果不明时沿用[设置保存核对流程](#来源连接与管理)，关闭确认框也不解除核对要求。不改变资产范围口径或触发链上操作。
- 名称、类别、资产范围与来源确认等写入只接受明确的成功确认；空 2xx 或无效响应保留输入并提示刷新核对，不显示已保存。备份恢复结果不明时关闭确认框并要求重新预演，不显示“重试恢复”。行情对比读取最多等待 15 秒，失败提供就地重试；K 线读取超时后可通过图表重试按钮重新拉取。
- 日期字段允许空值并显示「未设置」；可清空字段的日历提供「清空」入口并归还焦点，清空后打开日历落在可选范围末月，不按空字符串读取月份。来源范围校验退出日不早于起始日，跨序时暂停提交并显示错误提示。

## 集成插件

设置的插件页使用独立目录布局，顶部提供搜索、全部与已安装筛选、检查更新、从 GitHub 安装和导入入口；不并入数据维护的纵向设置面板。卡片显示名称、用途、开发者、版本与安装状态，有主页时提供链接；未发布的插件仍展示介绍，安装按钮禁用并显示“待发布”。操作贴底，按现有断点排列三、二或一列。账户接入与行情服务按能力提供不同操作；在线安装和更新先显示版本与发布仓库，导入先展示包信息，经确认后安装，沿用共享对话框和通知组件。

搜索与范围筛选组成同一工具栏，宽屏底部对齐，手机搜索独占一行；展示结果数量，搜索忽略首尾空白。区分目录读取中、目录为空、尚未安装和筛选无匹配；已有目录中的筛选无结果提供“清除筛选”，同时重置搜索及范围并将焦点放回搜索框。读取失败就地重试，保留已有目录和筛选，不把读取失败解释成无匹配。

GitHub 安装先输入仓库或 Release 地址并查看；多插件时使用共享选择器，再展示所选插件、开发者、版本、固定 Release 与摘要，最终确认才安装。查看和安装分别显示进行状态，失败保留输入与已有预览；明确拒绝允许重试或重新查看，结果不明遵循下述核对流程。页尾保留问题反馈与开发指南入口，GitHub 预览提供开发者问题入口；演示模式禁用安装动作。

插件目录读取最多等待 45 秒，GitHub 查看和本地包预览最多等待 30 秒，时限包含响应内容读取；失败保留已有目录或预览并允许重试，响应不完整时不进入确认。新目录读取取消旧请求，离开页面取消读取，迟到结果不覆盖当前状态。GitHub 查看期间可以取消并关闭对话框，安装期间仍防止误关。

目录操作、GitHub 安装与本地包安装共用写请求边界，最多等待 120 秒，包含响应正文；仅接受结构完整且体现所请求版本、启停或卸载结果的安装状态，损坏插件仍保留展示。会话失效即时锁定，服务端异常不等待读取正文。明确拒绝保留确认内容并允许重试；网络中断、超时、服务端异常或无效成功响应保留上次状态，暂停所有插件写操作。结果不明时提供新标签页核对当前插件的入口；服务端可能仍在处理，核对不能视为本次操作成功，确认未执行且处理结束后由用户恢复操作，不自动重传。关闭弹窗不解除核对要求，并将焦点交给页面上的核对入口；离开页面后不处理旧请求结果。

## 金融信息与隐私

业务合同统一见 [CONTEXT](../../CONTEXT.md) 与 [有效 ADR](../adr/)，三本投资账见 [ADR-0007](../adr/0007-unify-investment-books.md)。界面展示遵守这些合同，不在设计文档重新定义金额计入、完整性、汇率、本金或观测写入资格。

| 信息 | 呈现要求 |
| --- | --- |
| 金额与币种 | 保留合同要求的完整精度，金融数字使用 Doto，辅助信息使用等宽字体，显式币种、表格数值右对齐；不以 `1.2k`、省略号或动画隐藏实际值 |
| 涨跌 | 显式正负号；遵守设置中的 `red-up` / `green-up`，复用 `--error` / `--success`，不新造配色 Token |
| 未估值或缺失 | 数值位明确显示“未估值”或对应的不可用原因，不替换为零；趋势 tooltip 可在金额位显示“—”，币种独立对齐，并在预留的状态行明确说明未估值及数据质量，切换日期时保持浮层尺寸稳定；汇总完整性由领域结果决定 |
| 来源同步与时效 | 来源状态和数据覆盖分别展示；不把同步失败、数据过期、缺少持仓行情都统一解释为金额丢失或未授权 |
| 总额与明细 | 分层呈现来源总额和持仓，不暗示两者可以重复相加，不用差额反推未知持仓市值 |
| 待确认记录 | 保留待确认状态与可解释原因，不因名称或缺价就作结论 |

资产持仓表的市值、现价、价格变化与持仓浮盈亏沿用首页的 Doto 数字；百分号与数字同字体，币种使用小号等宽字体，数量、资产代码和缺失提示保留普通数据字体。价格变化与持仓浮盈亏遵循涨跌配色偏好，零值、缺失或隐藏金额时保持中性。

登录后的“隐藏关键信息”保留真实趋势曲线、日期、区间控件及来源分布列表；金额、数量、收益率、金额刻度与悬浮读数以 `••••••` 遮罩，沿用对应金融数值的 Doto 字体与字号。来源名称、数据状态、明细入口及缺失提示保留；切换时预留数值宽度，保持表格列宽、行高及币种位置稳定，时段标签保留，K 线入口在隐藏时保留位置并禁用；隐藏数值不带涨跌符号或涨跌色，tooltip 的尺寸占位也不保留真实数值。这是已授权页面的显示偏好，认证与锁定边界仍按 CONTEXT 执行。

持仓明细的时段标签独立在价格左侧、相对两行数字居中，不撑高数字行；现价、成本与相邻市值及盈亏列统一使用 16px 数字、1.5 行高与 4px 行间距，数值右对齐。股票与期权行使用相同的名称区高度，缺价原因使用 14px 普通数据字体，不以粗体抢占数字层级。完整行情时间保留在名称下方，延迟、保留行情等状态仍随时段显示，避免时间戳打断价格层级。

财务趋势复用 [AssetTrendPanel](../../src/ui/asset-trend-panel.tsx) 的区间、自定义日期、覆盖提示、tooltip 与缺失/隐私状态；总览、投资账与来源详情默认全部历史，业务指标由页面提供。日期切换使用「1周、1月、半年、1年、全部」五个紧凑文本按钮及自定义日期图标。默认在图下居中；投资账本的区间同时控制指标与记录，因此放在指标或记录上方，每个视角只出现一组。证券行情 K 线独立。

财务趋势的纵轴宽度随实际刻度文字自适应，切换币种、金额量级或收益率后仍完整显示数值，不通过裁切、缩小字号或省略金额适配窄屏。

证券行情弹窗的五日走势与各周期 K 线共用读数、坐标与十字线样式，周期切换使用图下居中的共享区间按钮。五日走势按交易所时区标出每个实际交易日，隔夜不补点连线；其余周期按可用宽度显示日期刻度。K 线提供开高低收与成交量，涨跌颜色跟随设置。主报价始终显示最新行情，历史选点日期与 OHLCV 独立显示。滚轮或双指缩放、拖动平移、双击重置，支持键盘逐点查看与加减键缩放；只在浏览历史时显示「回到最新」，不常驻缩放、全部、最新或刷新按钮，失败时提供重试。本次弹窗内短暂复用并预取周期数据，复用持仓已接收的行情，不另建连接或定时轮询 K 线。最新报价显示实际时段和交易所时间；仅常规盘报价投影当前柱，盘外报价不混入常规盘 OHLC。当前柱反映历史读取与已收到的报价，日 K 可用推送日内 OHLCV；不能确定当前周期成交量时显示「—」，不以日内累计量替代分时或周/月/年成交量。跨入缺失周期、行情重连或回到前台时补齐历史；读取期间收到的更新不被较早报价回滚。刷新保持缩放与历史位置，最新视野跟随新增数据；失败时保留原行情并明确提示，关闭或会话锁定后清除缓存。

投资账本的「记账记录」页头提供「导入历史记账」，复用核对后确认的导入流程；页面只展示生效记录，不单独展示原件与更正历史。待确认来源范围与旧资金核对提示继续置顶。

账本旧资金核对弹窗及候选项、作废确认与导入核对摘要的只读金额跟随隐私偏好遮罩，保留日期、币种和操作；不清除编辑输入。保存请求及响应内容共用三十秒时限，仅在服务端成功响应中明确返回不含 `error` 字段的 `{ok:true}` 对象后关闭；明确的业务拒绝保留输入并允许修正，超时、连接中断、服务端异常或响应内容不明时保留表单并暂停提交，提供新标签页核对最新记录的入口，由用户确认未保存后再继续编辑，不自动重传或宣称成功。收到 5xx 后立即进入核对状态，不等待错误正文。

核对入口按本次记录类型和日期打开记账记录；通用核对入口显示全部记录，避免隐藏资产估值。手工资产核对另列所选来源、日期的已存原始金额及保存时间，不以整本账汇总或跨日金额推断保存结果；金额仍遵守隐私偏好。查无记录时说明本次读取未找到，并提示刷新核对，不自动解锁重传。

来源详情的手工资产更新与账本保存共用财务保存弹窗及请求结果判定，沿用上述三十秒时限、保存确认与结果不明恢复流程；核对入口优先打开所属账本的记账记录，无所属账本时在来源详情核对指定日的原始记录；输入、日期与币种在核对期间保留并暂停编辑。保存与核对状态只由共享弹窗维护；离页卸载时取消请求，迟到的成功、失败或未授权响应不能刷新、关闭或锁定当前界面。取消客户端请求不代表服务端未保存，恢复编辑只解除本地核对状态，不自动重传。

A股资产弹窗的来源选项沿用自定义名称，按所选来源与日期读取已保存金额，没有记录时留空；切换前若金额已修改，在同一保存弹窗中确认放弃后再切换，继续编辑则保留原选择、输入、字段校验和保存反馈，并恢复切换控件的焦点；最终关闭后焦点回到打开入口。所选来源退出当前账本范围时保留输入并暂停提交，要求重新选择，不自动把金额关联到另一来源。备份恢复失败在确认弹窗内显示并保留预演与所选备份，允许重试；成功后重读来源与诊断、清除旧同步反馈，并提供来源管理与重新授权入口。

备份上传最多等待两分钟，超时或连接中断后释放操作锁并提示保存结果待核对；先重读备份列表、核对文件名与时间，再决定是否重传，不把超时当作服务端未保存，也不自动重传。

备份列表读取最多等待三十秒，失败或超时保留已有列表、选择及预演，释放读取状态并允许重试；该读取时限不用于导出或恢复写操作。

备份列表、预演、导出和上传的响应在共享请求边界校验，结构不完整或字段无效时不把无效数据写入界面、不显示完成。恢复仅在返回完整的恢复结果后显示成功；空响应、无效成功响应、连接中断或服务端异常均进入待核对，保留文件选择、关闭确认框并要求重新预演。列表重新读取或离开页面时取消旧读取，迟到响应不覆盖当前状态。

账本选择与收益／记录视角共用一个导航区，宽度足够时同行，手机按组换行。页头操作自然横排，手机按两列排列；表现区标题、截至日期与日期筛选组成一组。四项指标的标签与读数起点对齐，按可用宽度自然排成四列、两列或单列，不叠加分栏线。缺失数值使用普通状态文字，不保留无意义单位。历史与同步金额的真实差异放在紧凑的可展开行，日期与差额直接显示，原始金额及采用口径展开核对，不用灰底提示框或长说明挤占指标与趋势的位置。

记账记录默认显示出入金，可切换资产估值或全部记录；所选起止日均包含在记录范围内，切换类型或日期后回到第一页。同一本账切换收益与记录视角时保留日期范围。仅在入金金额下附带截至本笔的累计净投入；计算使用完整有效历史，筛选及分页不重置本金。不增加顶部汇总或估值列。

记录类型与日期筛选归为同一工具栏，控件统一 44px 高，窄屏按组换行。记录的日期与类型、金额、操作使用固定列对齐；窄屏将日期与类型放在左侧，金额与操作放在右侧。原币金额为主读数，折合金额及累计净投入保持次级层级，更正与作废保留独立点击区域。

资产持仓与历史覆盖共用来源筛选规则；当前来源从可选列表中移除时，回到「全部来源」并保留其他筛选，历史覆盖回到第一页。来源重命名、排序或同步状态变化不清除选择，已移除来源重新出现也不自动恢复旧筛选。

资产页的“持仓价格与市值观察”不分页，直接展示全部筛选结果。其他明细表格统一每页 20 条，分页前侧显示当前记录范围与总数，后侧将上一页、可编辑的当前页 / 总页数、「跳转」、下一页收成一组，不再重复排列页码。页码使用紧凑字段，聚焦选中当前值；输入有效页码后点击「跳转」或按 Enter，翻页与筛选均清除未确认输入，筛选回到第一页。空表不显示分页，数据减少时回到有效页。窄屏将记录范围置于控件上方，翻页和跳页仍保持一行。分页只裁切当前展示的明细，汇总与收益计算始终使用完整数据。

来源详情的持仓明细单页隐藏分页，底部将持仓数量与完整资产同步时间放在同一行，窄屏自然换行；多页保留共享分页。页脚与表格内容边缘对齐，分页与表格之间保留间距，不重复叠加分隔线；正常同步状态由卡片顶部展示，底部仅保留异常状态。

投资账本的趋势仅提供「总资产 / 收益率」两个选项，默认显示收益率，市场对比仅在收益率下展示。全部日期显示资产总额、累计净投入、累计收益与累计收益率；其他区间显示期末资产、区间净流入、区间收益与区间收益率，收益率曲线从所选起点重算。财务公式与端点缺失规则见 [CONTEXT](../../CONTEXT.md#投资账本)。累计收益不单独成图。

市场对比在初次读取和失败重试期间明确显示指数加载状态，失败后提供重试。同一来源范围、上海自然日的在途读取由共享层复用，连续重试不重复发起请求；读取时限同时覆盖响应内容，超时结果不进入缓存。

长桥入出金明细与趋势 tooltip 显示原币金额，港币记录另列账本已有的 USD 折算金额；原币为 USD 时只显示一次。整体本金与收益沿用 USD，不在展示时重新换汇或改写原始记录。

资金事件按发生日期贴在自身曲线上：有当天曲线值时使用真实数据点，缺少当天值但日期位于相邻真实观测之间时，沿已绘曲线定位视觉圆点；缺少的财务值仍为空，不补零或插值金额。首条观测之前、末条观测之后或整个区间没有估值时，不补造曲线或在横轴放点，资金记录仍可在记账记录查看。入金用中性实心圆点，出金用中性空心圆点，期初用更小的弱化圆点；同日入金与出金并存时使用实心内点与空心外环。不显示贯穿竖线或常驻事件文字，图下保留简洁入金/出金图例，具体金额沿用趋势 tooltip。

趋势悬停竖线即时跟随指针位置，提示框不使用移动过渡；日期按所在位置对应的上海自然日切换。当天没有实际记录时显示「暂无记录」，不吸附到相邻有记录的日期，也不插值金额；已有记录但未估值或过期时保留对应状态。手工记录沿用形成的曲线不代表后续日期新增了实际记录，市场对比曲线仍展示其各自当天的数据。

财务趋势不展示图下的数据覆盖统计块；估值异常、空态和 tooltip 中的缺失或过期状态仍按数据展示。投资账本选择全部日期时，资产曲线从首条完整资产估值开始，记账记录仍包含早期资金；资金记录早于首条完整资产估值且当前区间覆盖该空缺时，图前简短标明估值起点及早期资金的查看位置，不据资金补造资产曲线。今日资产变化将标签、金额、币种与比较日期紧凑排列，窄屏自然换行，不常驻解释性长句；该指标仍表示资产金额差，不能命名为投资收益。

趋势主线允许使用同色静态柔光，保留清晰线芯；线下点阵随主题反色，使用 8px 间距、1px 半径的小圆点，透明度从绘图区顶部最高 72% 向底部逐行线性淡出，使中下部点阵仍可辨认，形成上亮下暗的层次，不叠加实色填充或彩色光晕。点阵默认开启，可在“设置 → 偏好”选择“显示点阵 / 仅显示曲线”，控件与示例遵守 [设置偏好选择卡片](components.md#设置偏好选择卡片)；选择保存在当前浏览器并统一应用于各处财务趋势，演示模式不读取或保存此偏好。这是数据曲线的视觉强调，不推广为卡片投影。平滑插值应经过原始观测点且不产生额外极值；真实平段与陡变不为视觉效果改写。

敏感数据只通过服务端授权返回，不编码进点阵、占位符或纯客户端状态。授权摘要只显示范围、状态和校验时间，不回显凭证、私钥、助记词等密钥材料。Passkey、TOTP 与恢复流程遵守安全域合同。

锁定页不显示资产卡片、占位、真实来源身份或可分享资产内容。演示入口使用链接，数据使用固定虚构内容；演示与所有者服务的隔离边界以 CONTEXT 及当前源码为准，不能靠视觉遮挡代替权限隔离。

登录页使用纯色背景，不叠加背景点场、页头页脚分隔线或电脑外框。从 1024px 起采用认证区与电脑示意双栏，较窄屏幕收为居中的认证区并隐藏电脑。页头沿用应用 Logo，主标题直接使用“资产看板”，不叠加口号、锁定标签或重复说明；已有 Passkey 时以其为唯一主操作，已配置的 TOTP 作为次级入口，仅有 TOTP 时将其作为主操作。次级入口集中排列在主操作下方，主题切换位于页头，时钟位于页脚；首次预置沿用同一构图。

登录请求期间阻止重复认证。Passkey 设备流程取消或超时采用中性反馈，与连接中断和服务端拒绝分开；不将设备原始报错作为唯一提示。TOTP 限流遵守服务端 `Retry-After`，到期后恢复输入与提交并提示可重试；返回登录方式选择不重置限流期限，服务端安全限制保持有效。

首次 Passkey 预置同样防重复操作并区分设备取消、连接异常与服务端拒绝，仅在明确返回 `{ok:true}` 后宣告完成。提交后结果不明时暂停预置，引导返回所有者登录尝试刚创建的 Passkey；不调用需要所有者会话的状态接口，不直接重传。

登录页电脑采用 CRT 显示器、横置机箱和独立带线键盘，显示器通过独立脚盘与支架放置于机箱顶面。默认开机，屏幕使用静态只读数据流示意与扫描线纹理。电源仅控制示意屏幕，键帽只有按压反馈，不输入文字或影响认证；不播放装饰性的扫描、光带或数据流动画。

## 中文、语义与内容适配

- 页面语言为 `zh-CN`，术语沿用 CONTEXT；中文正文行高 1.5–1.7，西文与金融数字按角色排版。
- 字体回退由基础 Token 负责，不在页面重写字体栈；中文标签不因西文大写规则而过度拉开字距。
- 中文标点用全角，代码、路径与 Token 用半角等宽；不把金融数字替换为全角数字。
- 长名称、地址与错误信息允许换行，必要时使用 `overflow-wrap: anywhere`；不以固定高度裁切正文。
- 数据表在窄屏内横向滚动，不压缩或截断金融列；页面本身不产生无意的横向溢出。

## 文案与异常恢复

使用面向资产看板用户的正式、简短名称，不随意造词，不以“・”或其他中点串联标签。字段保留名称与必要单位；能从控件、标题和布局识别的信息不重复描述。财务计算口径、授权范围、不可恢复后果属于必要信息，放在相关详情或提交操作处。

暂无记录、无筛选结果、历史不足、无法读取分别表达。筛选无结果提供清除筛选；当前估值不完整提供检查来源；刷新失败给出原因与重试。始终显示已有数据的时间和完整性，不用零或装饰动画填补缺失值。

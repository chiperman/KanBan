# 页面模式：布局、信息与验收

本文维护页面组合与信息呈现。页面职责和路由以 [当前能力与源码导航](../current-baseline.md) 为准，组件接口见 [组件规范](components.md)，采用契约见 [DESIGN](../../DESIGN.md)。

## 页面骨架

实现入口为 [WorkbenchShell](../../src/ui/workbench-shell.tsx) 与 [product-layout.css](../../src/app/product-layout.css)。侧栏、页头与内容区通过细线和留白分隔，不用阴影强调层级。

- 桌面主导航为总览、资产、投资账本，设置位于侧栏底部；手机底栏显示四项。
- 侧栏展开宽度由 `--workbench-rail-width` 推导，当前为 160px；折叠状态沿用工作台实现，内容留白与导轨同步，不把展开宽度写死到各页。
- 页头承载标题与页面操作，采用细线分区，不包装成数据卡片。窄屏操作区允许换行。
- 当前页用 `aria-current="page"` 与中性反转或文字层级表达，不使用强调色。
- 主题跟随现有明暗及系统偏好能力；不能以历史“工作台固定暗色”的描述覆盖当前选择。

## 响应式

| 档位 | 组合规则 |
| --- | --- |
| ≥1200px | 显示桌面侧栏，内容为导轨留出空间 |
| <1200px | 隐藏桌面导航，使用底部移动导航；内容取消导轨留白，并预留导航高度、操作空间与安全区 |
| 640–1023px | 需要栅格的页面降为两列，跨列内容相应降级 |
| <640px | 单列为主，操作可占满整行，页内边距收为 16px；对话框按组件配方贴底或全屏 |

新增样式使用 0 / 640 / 1024 / 1200 四档边界；已有其他断点需按实际布局核定，统一见 [backlog](../backlog.md#存量样式与守门基线收敛)。不能只改数值而跳过受影响页面的组合关系。

移动导航高度由 `--workbench-mobile-navigation-height` 推导；底部留白计入 `env(safe-area-inset-bottom)`，确保内容和操作可滚动到末尾。

## 卡片与内容组合

按页面的信息关系决定栅格，不为了填满版面制造卡片。使用栅格时按宽度降为三列、两列或单列；同行需要对齐的卡片可等高，操作区由容器布局贴底，不依赖已移除的旧选择器。

当前实现中，通用 `.card` 使用 `--surface`、1px `--line` 与 `--r-md`，总览卡使用无边框玻璃面，部分数据模块使用透明材质。它们的分类与取舍尚待核定，见 [backlog](../backlog.md#卡片空态与字段密度核定)；不能把“所有卡片无边框”当作当前实现，也不因存量存在就推广新配方。认证玻璃面的合同由组件规范维护。

卡片不以悬停增加阴影。布局编辑若提供拖拽或缩放，需有非拖拽的等价操作；状态标记遵守 [项目适配](../../DESIGN.md#项目适配)。空态结构见 [组件规范](components.md#空态)，无内容时不堆占位卡片。

## 来源连接与管理

实现入口为 [AssetSourceDetail](../../src/ui/asset-source-detail.tsx) 和 [LongbridgeConnectionSummary](../../src/ui/longbridge-connection-settings.tsx)。

- 使用一个连续的设置面板，顺序为基本信息、连接与授权、显示、危险操作；不并排放置内容长度悬殊的卡片，也不拉高空白区域对齐。
- ≥1024px 每节按“标题 / 内容”两栏对齐；更窄时标题位于内容上方，<640px 字段标签与值、表单按钮、行操作继续纵向排列。内容和错误文字自然换行，无固定高度。
- 基本信息保留来源类型与名称编辑，不重复展示当前名称。来源标识默认折叠；手工来源在此维护资产类别，不出现连接与授权区。
- 连接与授权常驻账户、连接方式、只读权限及最近同步尝试时间；长桥版本、授权通道与最近读取方式放入“连接详情”。其他自动来源保留重新授权入口，观察钱包提供公开地址与资产范围入口。
- 来源生命周期、同步结果与通道检测分别表达；最近同步尝试不能标成成功校验。同步失败、检测失败与账户不一致直接显示，不藏在折叠详情中；仅有已连接状态时不使用成功色暗示实时检测通过。
- 卡片显示是独立的可逆操作；断开、恢复及永久删除位于明确的危险操作区，使用共享按钮与既有确认流程。业务后果以 [CONTEXT](../../CONTEXT.md) 为准。

## 命令面板

实现入口为 [CommandMenu](../../src/ui/command-menu.tsx) 与 [command-menu.css](../../src/app/command-menu.css)。遮罩使用 `--overlay`；面板使用 `--surface`、`--line-2` 与 `--r-md`，不加阴影。当前项用 `--raised` 与中性轮廓，快捷键提示使用等宽字体。

支持方向键移动、`Enter` 执行、`Esc` 关闭并归还焦点；可见焦点、可访问名称与命中区沿用组件规范。

## 金融信息与隐私

业务合同统一见 [CONTEXT](../../CONTEXT.md) 与 [有效 ADR](../adr/)，三本投资账见 [ADR-0007](../adr/0007-unify-investment-books.md)。界面展示遵守这些合同，不在设计文档重新定义金额计入、完整性、汇率、本金或观测写入资格。

| 信息 | 呈现要求 |
| --- | --- |
| 金额与币种 | 保留合同要求的完整精度，金融数字使用 Doto，辅助信息使用等宽字体，显式币种、表格数值右对齐；不以 `1.2k`、省略号或动画隐藏实际值 |
| 涨跌 | 显式正负号；遵守设置中的 `red-up` / `green-up`，复用 `--error` / `--success`，不新造配色 Token |
| 未估值或缺失 | 数值位明确显示“未估值”或对应的不可用原因，不替换为零；趋势 tooltip 可在金额位显示“—”，币种独立对齐，并在预留的状态行明确说明未估值及数据质量，切换日期时保持浮层尺寸稳定；汇总完整性由领域结果决定 |
| 来源同步与时效 | 来源状态和数据覆盖分别展示；不把同步失败、数据过期、缺少持仓行情都统一解释为金额丢失或未授权 |
| 总额与明细 | 分层呈现来源总额和持仓，不暗示两者可以重复相加，不用差额反推未知持仓市值 |
| 待确认记录 | 保留待确认状态与可解释原因，不因名称或缺价就作结论 |

资产持仓表的市值、现价、价格变化与平台盈亏沿用首页的 Doto 数字；百分号与数字同字体，币种使用小号等宽字体，数量、资产代码和缺失提示保留普通数据字体。

持仓明细的时段标签独立在价格左侧、相对两行数字居中，不撑高数字行；现价、成本与相邻市值及盈亏列统一使用 16px 数字、1.5 行高与 4px 行间距，数值右对齐。股票与期权行使用相同的名称区高度，缺价原因使用 14px 普通数据字体，不以粗体抢占数字层级。完整行情时间保留在名称下方，延迟、保留行情等状态仍随时段显示，避免时间戳打断价格层级。

财务趋势复用 [AssetTrendPanel](../../src/ui/asset-trend-panel.tsx) 的区间、自定义日期、覆盖提示、tooltip 与缺失/隐私状态；总览、投资账与来源详情默认全部历史，业务指标由页面提供。日期切换统一在图下居中，使用「1周、1月、半年、1年、全部」五个紧凑文本按钮及自定义日期图标，调用方不再选择展示模式。证券行情 K 线独立。

投资账本的「记账记录」页头提供「导入历史记账」，复用核对后确认的导入流程；「原件与更正记录」置于该页底部并默认折叠，不单设管理标签。待确认来源范围与旧资金核对提示继续置顶。

投资账本的趋势仅提供「总资产 / 收益率」两个选项，默认显示收益率，市场对比仅在收益率下展示；顶部保留资产总额、累计净投入、累计收益与累计收益率，累计收益不单独成图。

长桥入出金明细与趋势 tooltip 显示原币金额，港币记录另列账本已有的 USD 折算金额；原币为 USD 时只显示一次。整体本金与收益沿用 USD，不在展示时重新换汇或改写原始记录。

资金事件贴在自身曲线的真实数据点：入金用中性实心圆点，出金用中性空心圆点，期初用更小的弱化圆点；同日入金与出金并存时使用实心内点与空心外环。不显示贯穿竖线或常驻事件文字，图下保留简洁入金/出金图例，具体金额沿用趋势 tooltip；缺少对应曲线值时不补零或插值生成资金点。

趋势悬停竖线即时跟随指针位置，提示框不使用移动过渡；日期按所在位置对应的上海自然日切换。当天没有实际记录时显示「暂无记录」，不吸附到相邻有记录的日期，也不插值金额；已有记录但未估值或过期时保留对应状态。手工记录沿用形成的曲线不代表后续日期新增了实际记录，市场对比曲线仍展示其各自当天的数据。

总览与投资账本不展示图下的数据覆盖统计块；估值异常、空态和 tooltip 中的缺失或过期状态仍按数据展示。今日资产变化将标签、金额、币种与比较日期紧凑排列，窄屏自然换行，不常驻解释性长句；该指标仍表示资产金额差，不能命名为投资收益。

趋势主线允许使用同色静态柔光，保留清晰线芯；线下点阵随主题反色，使用 8px 间距、1px 半径的小圆点，透明度从绘图区顶部最高 72% 向底部逐行线性淡出，使中下部点阵仍可辨认，形成上亮下暗的层次，不叠加实色填充或彩色光晕。点阵默认开启，可在“设置 → 偏好 → 个性化”选择“显示点阵 / 仅显示曲线”，控件与示例遵守 [设置偏好选择卡片](components.md#设置偏好选择卡片)；选择保存在当前浏览器并统一应用于各处财务趋势，演示模式不读取或保存此偏好。这是数据曲线的视觉强调，不推广为卡片投影。平滑插值应经过原始观测点且不产生额外极值；真实平段与陡变不为视觉效果改写。

敏感数据只通过服务端授权返回，不编码进点阵、占位符或纯客户端状态。授权摘要只显示范围、状态和校验时间，不回显凭证、私钥、助记词等密钥材料。Passkey、TOTP 与恢复流程遵守安全域合同。

锁定页不显示资产卡片、占位、真实来源身份或可分享资产内容。演示入口使用链接，数据使用固定虚构内容；演示与所有者服务的隔离边界以 CONTEXT 及当前源码为准，不能靠视觉遮挡代替权限隔离。

登录页使用纯色背景，不叠加背景点场、页头页脚分隔线或电脑外框。从 1024px 起采用认证区与电脑示意双栏，较窄屏幕收为居中的认证区并隐藏电脑。页头沿用应用 Logo，主标题直接使用“个人投资资产看板”，不叠加口号、锁定标签或重复说明；已有 Passkey 时以其为唯一主操作，已配置的 TOTP 作为次级入口，仅有 TOTP 时将其作为主操作。次级入口集中排列在主操作下方，主题切换位于页头，时钟位于页脚；首次预置沿用同一构图。

登录页电脑采用 CRT 显示器、横置机箱和独立带线键盘，显示器通过独立脚盘与支架放置于机箱顶面。默认开机，屏幕沿用只读数据流示意，叠加仅限玻璃内的细扫描线与缓慢下扫的光带。电源仅控制示意屏幕与动画，键帽只有按压反馈，不输入文字或影响认证；关机、页面隐藏或电脑离屏时暂停屏内动画，减弱动效时保留静态内容与扫描线纹理，停止光带运动。

## 中文、语义与内容适配

- 页面语言为 `zh-CN`，术语沿用 CONTEXT；中文正文行高 1.5–1.7，西文与金融数字按角色排版。
- 字体回退由基础 Token 负责，不在页面重写字体栈；中文标签不因西文大写规则而过度拉开字距。
- 中文标点用全角，代码、路径与 Token 用半角等宽；不把金融数字替换为全角数字。
- 长名称、地址与错误信息允许换行，必要时使用 `overflow-wrap: anywhere`；不以固定高度裁切正文。
- 数据表在窄屏内横向滚动，不压缩或截断金融列；页面本身不产生无意的横向溢出。

## 页面验收

按授权和改动范围验证受影响页面；仅整理文档不触发浏览器验收，工程命令见 [设计契约](../../DESIGN.md#变更与验证)。

| 检查项 | 判据 |
| --- | --- |
| 响应式 | 检查受影响的四档边界与代表性 390×844 窄屏；页面无横向溢出，表格滚动限制在自身容器 |
| 导航与弹层 | 移动导航不遮挡内容，安全区留白有效；对话框内容和页脚可到达 |
| 文本缩放 | 200% 下不丢内容与操作，长中文和长金额可完整读取 |
| 主题与对比度 | 明暗均验证，跟随系统时选择有效；实际对比度符合基础规范 |
| 键盘与读屏 | 操作可达、焦点可见、弹层关闭后焦点归还；状态语义清楚，无重复播报 |
| 状态与动效 | 不只靠颜色表达，减弱动效时信息保留；金融方向、币种、覆盖与隐私状态准确 |

页面验收不能代替真实来源、调度或账户数据验收。

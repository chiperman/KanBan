# 页面模式：布局、信息与验收

本文维护页面组合与信息呈现。页面职责和路由以 [当前能力与源码导航](../current-baseline.md) 为准，组件接口见 [组件规范](components.md)，采用契约见 [DESIGN](../../DESIGN.md)。

## 页面骨架

实现入口为 [WorkbenchShell](../../src/ui/workbench-shell.tsx) 与 [product-layout.css](../../src/app/product-layout.css)。侧栏、页头与内容区通过细线和留白分隔，不用阴影强调层级。

- 桌面主导航为总览、资产、投资账本，设置位于侧栏底部；手机底栏显示四项。
- 侧栏展开宽度由 `--workbench-rail-width` 推导，当前为 160px；折叠状态沿用工作台实现，内容留白与导轨同步，不把展开宽度写死到各页。
- 页头承载标题与页面操作，采用细线分区，不包装成数据卡片。窄屏操作区允许换行。
- 当前页用 `aria-current="page"` 与中性反转或文字层级表达，不使用强调色。
- 主题跟随现有明暗及系统偏好能力；不能以历史“工作台固定暗色”的描述覆盖当前选择。

## 响应式

| 档位 | 组合规则 |
| --- | --- |
| ≥1200px | 显示桌面侧栏，内容为导轨留出空间 |
| <1200px | 隐藏桌面导航，使用底部移动导航；内容取消导轨留白，并预留导航高度、操作空间与安全区 |
| 640–1023px | 需要栅格的页面降为两列，跨列内容相应降级 |
| <640px | 单列为主，操作可占满整行，页内边距收为 16px；对话框按组件配方贴底或全屏 |

新增样式使用 0 / 640 / 1024 / 1200 四档边界；已有其他断点需按实际布局核定，统一见 [backlog](../backlog.md#存量样式与守门基线收敛)。不能只改数值而跳过受影响页面的组合关系。

移动导航高度由 `--workbench-mobile-navigation-height` 推导；底部留白计入 `env(safe-area-inset-bottom)`，确保内容和操作可滚动到末尾。

## 卡片与内容组合

按页面的信息关系决定栅格，不为了填满版面制造卡片。使用栅格时按宽度降为三列、两列或单列；同行需要对齐的卡片可等高，操作区由容器布局贴底，不依赖已移除的旧选择器。

当前实现中，通用 `.card` 使用 `--surface`、1px `--line` 与 `--r-md`，总览卡使用无边框玻璃面，部分数据模块使用透明材质。它们的分类与取舍尚待核定，见 [backlog](../backlog.md#卡片空态与字段密度核定)；不能把“所有卡片无边框”当作当前实现，也不因存量存在就推广新配方。认证玻璃面的合同由组件规范维护。

卡片不以悬停增加阴影。布局编辑若提供拖拽或缩放，需有非拖拽的等价操作；状态标记遵守 [项目适配](../../DESIGN.md#项目适配)。空态结构见 [组件规范](components.md#空态)，无内容时不堆占位卡片。

## 命令面板

实现入口为 [CommandMenu](../../src/ui/command-menu.tsx) 与 [command-menu.css](../../src/app/command-menu.css)。遮罩使用 `--overlay`；面板使用 `--surface`、`--line-2` 与 `--r-md`，不加阴影。当前项用 `--raised` 与中性轮廓，快捷键提示使用等宽字体。

支持方向键移动、`Enter` 执行、`Esc` 关闭并归还焦点；可见焦点、可访问名称与命中区沿用组件规范。

## 金融信息与隐私

业务合同统一见 [CONTEXT](../../CONTEXT.md) 与 [有效 ADR](../adr/)，三本投资账见 [ADR-0007](../adr/0007-unify-investment-books.md)。界面展示遵守这些合同，不在设计文档重新定义金额计入、完整性、汇率、本金或观测写入资格。

| 信息 | 呈现要求 |
| --- | --- |
| 金额与币种 | 保留合同要求的完整精度，显式币种、等宽数字、表格数值右对齐；不以 `1.2k`、省略号或动画隐藏实际值 |
| 涨跌 | 显式正负号；遵守设置中的 `red-up` / `green-up`，复用 `--error` / `--success`，不新造配色 Token |
| 未估值或缺失 | 数值位明确显示“未估值”或对应的不可用原因，不替换为零；汇总完整性由领域结果决定 |
| 来源同步与时效 | 来源状态和数据覆盖分别展示；不把同步失败、数据过期、缺少持仓行情都统一解释为金额丢失或未授权 |
| 总额与明细 | 分层呈现来源总额和持仓，不暗示两者可以重复相加，不用差额反推未知持仓市值 |
| 待确认记录 | 保留待确认状态与可解释原因，不因名称或缺价就作结论 |

财务趋势复用 [AssetTrendPanel](../../src/ui/asset-trend-panel.tsx) 的区间、自定义日期、覆盖提示、tooltip 与缺失/隐私状态；总览、投资账与来源详情默认全部历史，业务指标由页面提供。证券行情 K 线独立。

总览不展示图下的数据覆盖统计块；估值异常、空态和 tooltip 中的缺失或过期状态仍按数据展示。今日资产变化将标签、金额、币种与比较日期紧凑排列，窄屏自然换行，不常驻解释性长句；该指标仍表示资产金额差，不能命名为投资收益。

趋势主线允许使用同色静态柔光，保留清晰线芯；线下点阵随主题反色，不使用彩色光晕。点阵默认开启，可在“设置 → 偏好 → 个性化”关闭，选择保存在当前浏览器并统一应用于各处财务趋势；演示模式不读取或保存此偏好。这是数据曲线的视觉强调，不推广为卡片投影。平滑插值应经过原始观测点且不产生额外极值；真实平段与陡变不为视觉效果改写。

敏感数据只通过服务端授权返回，不编码进点阵、占位符或纯客户端状态。授权摘要只显示范围、状态和校验时间，不回显凭证、私钥、助记词等密钥材料。Passkey、TOTP 与恢复流程遵守安全域合同。

锁定页不显示资产卡片、占位、真实来源身份或可分享资产内容。演示入口使用链接，数据使用固定虚构内容；演示与所有者服务的隔离边界以 CONTEXT 及当前源码为准，不能靠视觉遮挡代替权限隔离。

## 中文、语义与内容适配

- 页面语言为 `zh-CN`，术语沿用 CONTEXT；中文正文行高 1.5–1.7，西文与金融数字按角色排版。
- 字体回退由基础 Token 负责，不在页面重写字体栈；中文标签不因西文大写规则而过度拉开字距。
- 中文标点用全角，代码、路径与 Token 用半角等宽；不把金融数字替换为全角数字。
- 长名称、地址与错误信息允许换行，必要时使用 `overflow-wrap: anywhere`；不以固定高度裁切正文。
- 数据表在窄屏内横向滚动，不压缩或截断金融列；页面本身不产生无意的横向溢出。

## 页面验收

按授权和改动范围验证受影响页面；仅整理文档不触发浏览器验收，工程命令见 [设计契约](../../DESIGN.md#变更与验证)。

| 检查项 | 判据 |
| --- | --- |
| 响应式 | 检查受影响的四档边界与代表性 390×844 窄屏；页面无横向溢出，表格滚动限制在自身容器 |
| 导航与弹层 | 移动导航不遮挡内容，安全区留白有效；对话框内容和页脚可到达 |
| 文本缩放 | 200% 下不丢内容与操作，长中文和长金额可完整读取 |
| 主题与对比度 | 明暗均验证，跟随系统时选择有效；实际对比度符合基础规范 |
| 键盘与读屏 | 操作可达、焦点可见、弹层关闭后焦点归还；状态语义清楚，无重复播报 |
| 状态与动效 | 不只靠颜色表达，减弱动效时信息保留；金融方向、币种、覆盖与隐私状态准确 |

页面验收不能代替真实来源、调度或账户数据验收。

# 04 · 页面模式

---

## 1. 页面骨架

```
.workbench-shell                      min-height: 100dvh
├── .workbench-sidebar                固定定位、宽 160px、右边 1px --line、底 --surface
└── .workbench-shell-content          padding-inline-start: 160px
    └── .page                         width: min(100%, 1280px)、padding 32/40/64
        ├── .page-header              仅底部 1px --line，无圆角、无背景
        └── 内容区
```

- **导轨宽度**由 token 推导：`--workbench-rail-width: calc(var(--vibe-space-16) * 2 + var(--vibe-space-2) * 4)` = **160px**。不要写死数字。
- **页头是"细线页头"，不是卡片**：`display: grid; grid-template-columns: minmax(0, 1fr) auto`，只有一条底部细线。它承载标题与右侧操作，不承载数据。
- **侧栏与内容之间用 1px 细线分隔**，不用阴影、不用色块。

### 侧栏导航状态

导航标签用 `--f-mono`。当前页由 `aria-current="page"` 表达，配合反转或 `--display` 文字，**不使用强调色**。

---

## 2. 响应式

| 档位 | 行为 |
|---|---|
| **≥1200px** | 显示固定侧栏与桌面导航；内容区左侧留出导轨宽度 |
| **<1200px** | 桌面导航 `display: none`；启用底部移动导航。内容区取消左侧留白，并在底部预留 `移动导航高度 + 控件高 + 32px + env(safe-area-inset-bottom)` |
| **640–1023px** | 卡片栅格降为两列；跨 3 列的项目降为 2 列 |
| **<640px** | 单列；控件占满整行；对话框贴底或升为全屏；页内边距收到 16px |

移动导航高度同样由 token 推导：`--workbench-mobile-navigation-height = calc(var(--vibe-control-height) + var(--vibe-space-4))`。

> **规范的断点是这四档（0 / 640 / 1024 / 1200）**。仓库现状里还散落着 359、720、959、1359、1439 等值——这是既有实现的偏差，见 [`07-deviation-register.md`](07-deviation-register.md)。**新增样式只允许使用这四档**，额外断点需在代码评审中说明理由。

---

## 3. 卡片栅格

- 栅格：`.card-grid`，3 列 → 2 列 → 1 列，间距 `--vibe-space-3`（12px）。
- **同一行卡片等高**：`align-items: stretch` + `grid-auto-rows: 1fr` + `.card-grid > .card { display: flex; flex-direction: column }`。
- **操作区贴底**：`.card-actions { margin-top: auto }`，并向上边距取负以贴到卡片边缘，顶部 1px 细线 + `--raised` 底。
- 跨列：`.span-1 / .span-2 / .span-3`，窄屏逐级降级。
- 拖拽编辑态由 `.layout-editing` 表达（虚线轮廓、抓取指针），拖拽预览用 `--display` 轮廓——**不使用阴影**。

卡片材质有两类，用途不同：

| 类型 | 材质 | 用途 |
|---|---|---|
| 数据模块 | 透明，仅细线与留白 | 总览里的来源模块（`.asset-source-card`），点场在模块之间可见 |
| 玻璃面板 | `--glass` + `blur(12–16px)`，无边框 | 总览卡、来源详情页卡、认证面板 |

**不要给卡片加边框，也不要用阴影表达层级。**

---

## 4. 命令面板

- 遮罩 `z-index: 50`，底色 `--overlay`；面板 8px 圆角、1px `--line-2`、`--surface`、无阴影。
- 快捷键提示用 `--muted` 等宽字体。
- 当前高亮项：`--raised` 底 + 1px `--line` 轮廓，**不用强调色**。
- 支持键盘上下移动、`Enter` 执行、`Esc` 关闭并归还焦点。

## 5. 状态表达模式

数据状态一律遵循 **形状 → 标签 → 颜色** 的顺序，且**颜色只落在数值上**。

| 场景 | 表达 |
|---|---|
| 来源同步失败 | 来源级状态标签 `error` + 数据健康中可展开的失败原因。**最后成功数据继续计入总资产**，不降低总额估值完整性 |
| 数据过期 | 沿用金额完整的过期数据不因此变成"不完整观测"。失败状态在来源级展示，**不要求总资产卡持续显示警告** |
| 未估值 | 数值位显示「未估值」，并使总资产标明"汇总不完整"。**绝不折算为零** |
| 持仓行情未接入 | 属于"明细覆盖不完整"，**不降低总额估值完整性**，也不得把账户总额与已知持仓的差额解释为该持仓市值 |
| 持仓级缺失 | 明确降级，不伪造成本或行情 |
| 不可读代币 | 默认收起、保留待确认状态，**不因名称或缺价就断言为垃圾代币** |

**动效可以消失，状态文字不可以消失。**

## 6. 金融真值表达

产品是只读资产看板，数字的可信度优先级高于视觉表现。

### 6.1 涨跌配色

- 默认遵循中国内地市场惯例：**涨用红、跌用绿**。
- 由 `data-profit-color-scheme="red-up|green-up"` 与 `data-profit-direction="positive|negative"` 两个属性共同决定，用户可在设置中切换到国际惯例。
- 颜色是**增强**，不是唯一线索：数字必须自带显式正负号。
- 涨用 `--error` / 跌用 `--success`（或按配色方案互换），**不新造涨跌颜色 token**。

### 6.2 数值呈现

- **保留完整精度**，不做四舍五入式截断，不使用 `1.2k` 这类缩写。
- **等宽对齐**：`font-variant-numeric: tabular-nums`，表格数值右对齐。
- **显式币种**：每个金额都带单位（`USD` / `CNY` / `HKD`），不依赖上下文推断。
- 计价货币可切换，**持仓与账本仍保留原始币种**；历史金额沿用当时的汇率观察，不用当前汇率重算。
- 汇总与明细的关系必须分层表达：来源总额是权威金额，**不要求等于持仓明细之和**。

### 6.3 敏感信息

- 只显示授权状态、最近校验时间和权限摘要。
- **绝不回显凭证原文、助记词、私钥或任何密钥材料。**
- 敏感数值只经服务端授权返回，不得编码进装饰性点阵、占位符或纯客户端状态。
- 身份验证、TOTP、恢复码属于安全域行为，**不是视觉状态**。

### 6.4 演示模式

演示模式渲染进程内固定虚构数据：**不读取所有者服务、不请求资产 API、不写入本机、不展示真实资产内容或资产布局**。演示模式下的界面不得复用真实来源身份。

## 7. 空白与引导

- 空态配方见 [`03-components.md`](03-components.md) 第 18 节。
- **没有内容时不要用占位卡片墙**。锁定页尤其不得展示资产卡片、资产占位、来源身份或任何可分享内容。
- 演示模式的入口可以出现在锁定页，但必须以链接形式，而不是以"预览数据"的形式。

## 8. 中文排版补充

| 项 | 要求 |
|---|---|
| 正文行高 | 1.5–1.7（产品正文用 1.5，说明文案用 1.65–1.7） |
| 字体回退 | 由 `--f-ui` / `--f-head` 的栈自动完成，不要在页面里另写字体栈 |
| 标签大小写 | 中文标签不受 `text-transform: uppercase` 影响；不要把中文标签的字距拉到 `.12em` 以上 |
| 数字与西文 | 与中文混排时保持等宽对齐，不要在中文里插入全角数字 |
| 全角／半角 | 标点使用中文全角，代码、路径、token 名使用半角等宽 |

# 05 · 无障碍与响应式

无障碍写在地基里，而不是事后补。以下每一条都是交付门槛，不是"尽善尽美"的可选项。

---

## 1. 对比度（WCAG AA）

| 内容 | 最低比例 |
|---|---|
| 正文文字 | **4.5:1** |
| 大字（≥18.66px 粗体 或 ≥24px） | **3:1** |
| 图形与界面控件边界 | **3:1** |

**强制规则**

- 强调色作为**前景**时必须使用 `--accent-text`（暗色 `#ff4438`、亮色 `#c2141c`），**不得直接用填充红 `#d71921` 当文字色**。
- `--success` / `--warning` / `--error` 在亮色主题下会压深，这正是为了保对比度——不要绕过 token 自己写浅色。
- `--muted`（`#5a5a5a` / `#9a9a9a`）只用于占位符、刻度、最弱说明，**不得承载必须读懂的信息**。
- 状态色落在数值本身，不落在整行背景上——大面积色底会同时压垮对比度与主次。

---

## 2. 键盘可达

| 组件 | 键盘契约 |
|---|---|
| 全局 | Tab 顺序与视觉顺序一致；无键盘陷阱；所有可点元素可聚焦 |
| 对话框 | 焦点移入遮罩内并循环；`Esc` 关闭；关闭后焦点归还原触发元素；打开时锁定 body 滚动 |
| 下拉菜单 | `ArrowDown` / `ArrowUp` 循环、`Home` / `End` 首尾、`Esc` 关闭并归还焦点、失焦即关闭 |
| 下拉选择 | `Enter` / `Space` 展开，`Esc` 收起，方向键在选项间移动 |
| 分段条 | `role="img"` + `aria-label` 提供整体语义（它不是可交互控件） |
| 验证码 | 真实 `<input>` 承载输入（`inputMode="numeric"`、`autocomplete="one-time-code"`、`pattern`），视觉槽位 `aria-hidden` |
| 日历 | 月切换与日期按钮均可聚焦；今天与已选状态可被读屏识别 |
| 拖拽编辑 | 必须提供非拖拽的等价操作路径 |

---

## 3. 可见焦点

焦点可见性不是可选项——它是键盘可用的前提。

| 元素 | 焦点样式 |
|---|---|
| 按钮 | `outline: 2px solid var(--primary)`，`outline-offset: 3px` |
| 输入框 / 下拉触发器 | 边框色转 `--primary`（无发光、无强调色） |
| 菜单项 | `outline: 2px solid var(--primary)`，`offset: -2px` |
| 下拉选项 | `outline: 1px solid var(--primary)`，`offset: -1px` |

**不要用 `outline: none` 移除焦点环**，除非提供了同等可见度的替代。

---

## 4. 命中区与触控

- **交互元素的命中区不得低于 40px。**
- 标准控件高 44px（`--vibe-control-height`），紧凑控件 40px（`--vibe-control-height-compact`）。
- 可见轮廓可以很薄——状态标签可见高 24px，刷新按钮可见高 24px——但**必须通过包裹层或伪元素把命中区外扩到 40px**。
- 移动端底部导航要为 `env(safe-area-inset-bottom)` 留出空间。
- 触控目标之间至少留出 8px 间距，避免误触。

> 这是本产品对上游的显式适配条款（`DESIGN.md` 第 3 节）：可见控件可以保持上游 6px 技术圆角与轻薄轮廓，但命中区不随之缩小。

---

## 5. 减弱动效

运行时共有 9 处 `@media (prefers-reduced-motion: reduce)` 规则（`product-layout.css` 7 处、`vibe-components.css` 1 处、`command-menu.css` 1 处）与 5 处 TS 侧 `matchMedia("(prefers-reduced-motion: reduce)")` 检查。

减弱动效时的行为：

- 过渡被移除（`transition: none`）。
- 计数动画直接落位，不播放插值。
- 装饰性旋转（如刷新图标）停止。
- **状态文字必须保留。** 动效可以消失，信息不可以消失。
- **错误绝不用抖动表达。** 用颜色 + 文字。

---

## 6. 文本缩放与溢出

- 文本放大到 **200%** 不破版、不丢内容。
- 不使用固定高度容器承载可换行文字。
- 数据表在窄屏**横向滚动**，而不是压缩或截断列。
- 长 token 名、长地址、长错误信息使用 `overflow-wrap: anywhere`。
- 不用 `text-overflow: ellipsis` 隐藏金融数值——数值要么完整显示，要么如实标注"数据不足"。

---

## 7. 色彩无关性

- 每个状态都必须有**形状或文字**作为第一线索，颜色是第二层。
- 状态标签的圆点只是载体；标签文字本身必须能读懂。
- 涨跌必须带显式正负号；即便颜色被忽略，方向依然明确。
- 不可读/未估值的行不仅有颜色，文案本身写明"未估值"或"数据不足"。

---

## 8. 中文与语义

- 页面语言声明为 `zh-CN`。
- 界面文案使用产品术语表（见 `CONTEXT.md`）中的词，例如「未估值」「断开来源」「删除来源数据」「当日基准」——不要让同一概念出现两种叫法。
- 图标一律 `aria-hidden="true"`，语义由相邻文字提供；纯图标按钮必须带 `aria-label`。
- 异步状态用 `role="status"` 或 `aria-live` 播报，但**不要制造第二行可见文案**——可见标签放在控件内，详细文案留给读屏。
- 装饰性点阵、SVG 插画必须 `aria-hidden` 且带 `focusable="false"`。

---

## 9. 响应式验收清单

| 检查项 | 判据 |
|---|---|
| 文档宽度 | 390×844 视口下 `document.scrollWidth === 390` |
| 无横向溢出 | 遍历所有元素，右边界不超过视口宽度 |
| 四档断点 | 0 / 640 / 1024 / 1200 各验证一次 |
| 移动导航 | <1200px 时桌面导航隐藏、底部导航可见且不遮挡内容 |
| 触控 | 移动端所有可点元素命中区 ≥44px |
| 对话框 | 窄屏贴底或全屏，页头页脚吸顶，内容可滚动到末尾 |
| 表格 | 窄屏横向滚动，无列截断 |
| 主题 | 暗色与亮色各验证一次；产品工作台保持暗色 |

# 生产服务生命周期

- `composition.ts` 的进程级槽保存服务。重复请求及兼容模块重载复用同一对象；独立 CLI 进程拥有自己的服务。
- 生产与测试都提供必需的来源详情和规范投资账本服务，页面不按环境切换旧账本实现。账本迁移、校验和更正规则共用 [InvestmentBookLedger](../../src/server/investment-books.ts)，SQLite 与内存适配器分别负责持久化与测试状态。
- 账本写操作仅将写入前明确的输入与业务冲突归为 `InvestmentBookCommandError`，接口返回 400，允许修正后重试。[错误边界](../../src/server/investment-book-errors.ts) 只转换纯校验中的已知领域错误；已有账本读取、迁移、事实读取及实际持久化不进入该转换。未知执行异常返回 500 和结果待核对提示，不回显底层异常，也不承诺未写入；迁移及自动资产写入继续使用原始状态校验，不能归为本次表单输入错误。
- 公共 `getServices()` 保持同步，不静态加载测试替身。测试装配归属 [testing/composition.ts](../../src/server/testing/composition.ts)，Next.js 由 [instrumentation.ts](../../src/instrumentation.ts) 在 `APP_ENV=test` 的 Node 启动阶段注入工厂；直接运行的测试先通过测试入口初始化，生产环境拒绝注入。
- `production.ts` 只组装端口；`persistence/` 持有数据库、迁移和适配器，`credentials/` 保存秘密与所有者认证，`source-connections.ts` 协调授权与业务状态。旧公开导出继续兼容。
- 来源读取统一通过插件管理器；全部外部来源与 CoinGecko 服务从正式数据目录加载独立包，核心没有生产内置供应商回退。包不随应用更新目录切换，浏览安装、停用与升级规则见 [来源插件](asset-sources.md#独立包安装与生命周期)；网页与后台必须使用同一插件目录。
- 插件注册表原子切换后，各进程在下一次请求加载变化；不重建认证、SQLite 或预览存储。长桥只在其自身包或启用状态变化时更换 worker，其他包的安装保留 OAuth 会话与订阅。应用代码、底层服务或存储实现变更仍需重启。
- SQLite 实例独占其连接，启动依次设置 PRAGMA、Schema 迁移、完整性校验和权限收紧。旧 JSON 不在运行时导入；需要迁移时单独执行 `pnpm migrate:json-to-sqlite`，迁移入口会校验目标库为空并保留源文件备份。Schema 模块借用该连接和事务，不自行连接。初始化失败关闭连接；正常连接与服务同寿命，由进程退出回收。
- 业务备份的导出与恢复预演在同一个只读事务内读取完整业务快照，不触发账本迁移；WAL 下其他连接可继续提交。恢复在持有写事务后重新核对当前历史及丢弃确认，再整批替换，遗漏历史事实发生变化须重新预演。第 1 版备份不含旧资金记录，预演列明将丢弃的数量，并按同样规则要求明确确认。
- 秘密恢复在读取来源引用后执行；ReadySecretStore 和来源连接等待同一恢复 Promise，失败向调用者传播。
- 长桥通过核心 RPC 门面调用插件的 [连接路由](../../plugins/longbridge/src/longbridge-connections.ts) 统一读取，支持仅 CLI、仅 SDK、CLI 优先且 SDK 备用。新连接默认 CLI，旧连接兼容为 CLI 优先。资产、每日历史、指数、持仓 K 线与正式日结均服从同一选择；读取前后核对同一真实账户，两种方式都失败时保留上次快照。CLI/SDK 不各建一份账本，不参与本金计算。
- 新增来源及来源的「连接与管理」提供自动检测与方式选择。检测的是 KanBan 服务所在机器；「重新检测 CLI」只检查并更新 CLI，保留 SDK 的检测结果。CLI 已登录可直接预览确认，无需手动启动 serve（stdio JSON-RPC）。未登录可通过官方一次性授权码登录；不自动安装 CLI 或替换已登录账户。SDK 使用独立 OAuth 与 Keychain，按需加载原生扩展。仅 CLI 无需 SDK 配置和构建，仅 SDK 不启动 CLI serve。
- 同一长桥连接服务的 CLI 登录从安装及授权预检查开始互斥，直至命令完成或失败才释放；预检查期间的重复请求也不能启动第二次登录，所有退出路径均释放互斥。
- CLI 账户核验按批次串行执行，读取后的核验使用新查询。K 线、指数及日结收盘价按来源连接引用复用 serve，空闲 60 秒回收，读取失败或连接引用变化时关闭旧连接。上述行情读取每个通道限时 25 秒；CLI 优先且 SDK 备用时，CLI 失败或超时后仍有独立的 SDK 读取预算。
- CLI 行情使用推送，SDK 行情每 15 秒轮询；双方式在 CLI 失败时使用 SDK，并定期重试 CLI。流订阅检查来源及账户绑定变化，关闭后释放子进程。行情在页面合并显示，不逐 tick 写库；数据库仍由既有刷新周期保存最近成功快照，每日历史按来源和日期幂等更新。
- 市场对比采用历史指数日 K，不是实时推送。服务端按上海日期与已连接来源身份在内存中缓存并合并并发请求，两个指数依次读取，避免 CLI 并发身份检查返回不完整账户信息；每次请求仍验证所有者会话及来源，失败或空数据不缓存。客户端同日共享行情，切换指标或指数不清空已读曲线，跨天及回到前台时检查更新；锁定或来源身份变化后不复用旧客户端缓存。缓存不包含账户金额或收益计算结果，HTTP 响应仍为 `no-store`。
- 修改服务端口、缓存格式或底层存储实现后应重新启动应用。兼容热更新用于已有服务的复用，不保证替换进程中已存在的类实例。
- 离线生命周期测试使用临时目录，覆盖新进程、模块重新求值、重复获取和重启数据保留；CLI 测试单独验证命令入口。历史验证只对应其提交与运行范围，不能代替当前真实服务器验收。

## 后台自动采集

- [后台服务](../../src/server/background-collection.ts) 独立于浏览器会话。Mac 用户登录后，网页生产服务常驻，采集任务每分钟检查一次；到期后执行每小时全量读取，失败来源在该轮开始后第 5、15 分钟补试。补试前重核来源，跳过已恢复或断开的来源；次数及后续计划在读取前持久化，异常退出后不重放已占用轮次。时间按轮次开始计算，不固定在整点；补试与手动单来源刷新不重置小时周期。网页自动刷新复用同一持久化周期。
- 每次检查也按十五分钟间隔调用正式日结执行器，仍遵守独立收盘窗口。使用综合后台时，不要同时保留旧的独立日结任务。睡眠、关机期间不运行；恢复后处理到期任务，不补造遗漏日的数据。
- 使用 SDK 的长桥来源（含 SDK 备用）每 24 小时只检查一次本地凭证到期时间，距到期不超过 24 小时才联网续期，不读取资产；仅 CLI 或已断开来源不加载 SDK。授权与续期共用只读权限白名单，省略 scope 时沿用请求范围。暂时失败在本轮开始后第 5、15 分钟各补试一次，次数与计划持久化；明确拒绝或越权则停止联网重试，等待重新授权。异常在设置中显示，独立于 CLI 资产采集结果。
- SQLite 按来源保存带 token 与过期时间的租约，覆盖网页、后台、手动和正式日结读取；租约比单来源超时预算多五秒，进程退出后可过期接管。原子提交核对来源身份、凭证、生命周期和时间顺序，同一事务写入最新快照与当日累计观测；旧 token 不能提交或释放新租约。
- 设置中的状态查询只读，不触发采集；下一次采集时间排除已恢复来源的旧补试计划。心跳表示近期检查过，批次结果表示读取情况，今日覆盖表示当日有效观测，两者不能互相替代；首次完整时间来自当日基准。来源授权过期仍需重新授权，网页登录过期或关闭网页不停止后台。
- 后台心跳、补试计划和租约属于运行状态，不进入业务备份；历史观测、基准和正式日结仍按已有业务备份合同保存。
- 已显式启用的长桥逐日资产补取复用网页全量刷新与后台检查，不另建调度任务；断点、限速与口径见 [来源接入](asset-sources.md#长桥逐日资产)。它补平台可查询的官方历史，不使用当前快照反推漏采日，也不写正式日结。

### 永久运行副本

后台不能长期指向会被移除的开发 worktree。先准备独立源码、依赖与生产构建，再安装登录任务：

```sh
pnpm runtime:prepare "$HOME/Library/Application Support/KanBan/runtime-v1" \
  --data-dir "$HOME/Library/Application Support/KanBan/data" \
  --env-file /绝对路径/.env.local --port 3001
cd "$HOME/Library/Application Support/KanBan/runtime-v1"
pnpm background:launchd print
pnpm background:launchd install
pnpm background:launchd status
```

[准备脚本](../../scripts/prepare-runtime.mjs) 不覆盖已有目录，不复制业务数据，也不安装任务；它复制当前源码（包括未提交且未忽略的修改），独立安装依赖和构建；已安装插件和 SDK 产物位于数据目录的插件包中，不随运行副本复制，保存 `.kanban-runtime.json`。构建使用一次性空数据目录，不接触正式库。运行副本禁止 `pnpm dev`。

日常开发完成后，在开发仓库根目录执行：

```sh
pnpm runtime:update
```

[更新命令](../../scripts/update-runtime.mjs) 自动读取已安装的网页与采集任务，要求两者属于同一个 3001 正式副本，沿用其数据目录、`.env.local` 和登录入口；不会复制开发数据或替换来源凭证。`pnpm runtime:update --check` 只检查配置、显示更新目标，不构建或切换。

新版在独立目录安装依赖并构建，期间旧版继续提供网页和采集。构建失败保留旧版；构建通过后暂停新后台批次并等待当前批次退出，再短暂重启网页、切换任务。安装与回退加载任务时，launchd 的临时 I/O 错误最多重试三十秒，其他错误立即报告。更新通过进程锁互斥；切换前使用 SQLite 在线接口保存数据库和原任务至新版 `.runtime-rollback/`，不直接复制可能遗漏 WAL 的主文件。启动后校验新构建的静态资源、首页及后台实际检查心跳；失败自动恢复原任务，保留正式数据库。旧副本保留用于回退，不自动清理。

采集的小时锚点、补试计划和历史记录仍来自同一个正式数据库，不因更新重置；切换期间到期的任务在恢复后处理。更新进程存活时后台跳过新批次，进程异常退出后暂停标记不阻塞采集。若进程被强制杀死而遗留更新锁，应先核对锁目录 `owner.json` 中的进程与任务实际状态，再移除锁重试。自动回退恢复代码与任务，不自动覆盖已写入的业务数据；不兼容的数据结构变更仍需独立迁移方案。网页服务重启后可能需要重新登录，Passkey、备用登录及来源授权继续沿用。

首次沿用现有数据时，先停止旧服务，完整备份并复制原数据目录，包括 SQLite、凭证、所有者认证与外部服务配置；保留原 `PAD_SECRET_ENCRYPTION_KEY`。不要让旧版开发进程与新版后台并行写正式库。开发默认端口 3000，正式副本默认 3001，使用不同数据目录与构建目录；复制的数据从分离后各自独立。

[launchd 管理脚本](../../scripts/background-launchd.mjs) 创建当前用户的 `com.xiaox.kanban.web`（持续运行）和 `com.xiaox.kanban.background-collection`（每分钟检查），固定 Node、PATH、数据目录与登录入口，日志保存在正式数据目录。默认入口为 `http://localhost:3001`；需要远程入口时用 `--origin` 指定现有 HTTPS 入口，并同步其转发端口。所有者登录保护保持生效；本机采集不需要网页 Cookie。

`pnpm background:run` 是一次真实后台检查，必须显式提供绝对路径 `KANBAN_DATA_DIR`，拒绝 `APP_ENV=test`；排查时不能将它当演示命令运行。安装、移除任务与真实数据迁移分别按本次操作授权执行。

## 正式日结

- [日结执行器](../../src/server/settlement/formal-daily-settlement.ts) 使用独立只读采集与持久化，不调用实时刷新的记录写入路径，不改写实时资产快照、当日基准或每日趋势观测。
- 持有证券时按相关市场交易日历及已确认的常规盘日 K 收盘确定锚点；无证券时使用上海自然日加密资产截点。休市、半日市与夏令时不能由固定钟点代替。
- 日结采集按来源独立保存市场集合、账户身份和观测时间，供后续检查及进程重启后判断窗口；不保存价格或持仓，也不触发窗口外全量估值。同一来源较新的实时快照替代旧市场证据，失败采集不清除已有发现。该运行状态不进入业务备份，永久删除来源或恢复业务数据时清除。
- 每个锚点只保存一批记录；[SQLite 写入](../../src/server/persistence/sqlite-formal-settlements.ts) 通过唯一键忽略重复插入，重复运行或进程重启不能覆盖既有金额。采集结束后再次核验窗口，窗口外记录漏采，不用后续持仓、价格或汇率补造历史总额；证据不足明确降级。
- [CLI](../../scripts/run-formal-daily-settlement.ts) 与页面使用同一服务装配和 `KANBAN_DATA_DIR`。本机 [launchd 管理脚本](../../scripts/formal-daily-settlement-launchd.mjs) 的安装、启停不是构建或启动页面的副作用，需明确操作授权。
- 设置页的 [调度状态读取](../../src/server/settlement/formal-settlement-scheduler.ts) 只查询本实例配置与加载证据，不安装任务、不采集资产，也不把“已加载”解释为采集健康或真实验收通过。未完成事项见 [待办](../backlog.md)。

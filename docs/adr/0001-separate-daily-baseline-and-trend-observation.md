# 区分日初基准与每日趋势观测

总资产历史同时需要稳定的今日比较基准和能够反映每日变化的趋势节点。每个上海自然日首次成功同步同时建立不可改写的“日初基准”和初始“每日趋势观测”；日初基准仅用于计算今日资产变动，后续成功同步只更新每日趋势观测。没有后续观测或只有既有日快照时，首次观测就是当天最佳已有趋势点，不需要伪造收盘值，也不需要仅为口径变化清空历史。

每日趋势观测可以是不完整观测。趋势保留并显式区分其已知金额，不补零、不沿用更早的完整值；如果所选区间的起点或终点不完整，则区间资产变动不可用。

趋势区间按连续上海自然日计算，而不是按已有观测条数计算。缺少观测的日期保留为断点；“全部”从首次观测日期延伸至当前日期。

当天唯一的首次观测只要完整，也可以作为区间资产变动的端点。区间资产变动展示两个端点的实际覆盖日期，不展示几点几分，只表达资产金额差，不解释为投资收益。

趋势区间边界缺少观测时，区间资产变动使用区间内首尾两个完整观测，并标明实际覆盖日期；不读取区间外观测补值，也不沿用旧值。少于两个完整观测时，区间资产变动不可用。

上海自然日内每次价格或持仓成功刷新都更新当天的每日趋势观测，日初基准保持不变。刷新失败时保留最后一次成功趋势观测并标明过期或不完整，不写入零值；进入新的上海自然日后，首次成功刷新重新建立日初基准和初始趋势观测。

# 从外部资金进出派生组合投资盈亏

日期：2026-08-09

状态：已采用

## 背景

每日资产观测只能说明组合在某一时点的价值。把相邻资产观测之差直接称为收益，会把外部入金和出金误判为投资盈亏；从来源持仓、平台交易或账户差额反推本金又会扩大凭证和交易隐私范围，并无法可靠覆盖平台间转账、换仓或缺失历史。

## 决策

新增独立的投资资金进出账本，只记录初始投入、外部入金和外部出金。组合投资盈亏由完整资产总额减累计净投入派生；区间投资盈亏由区间资产变化减该区间净外部投入派生。比例使用明确标注的资金发生日加权 Modified Dietz 计算，端点资产、账本换算或分母不可靠时显示数据不足。

账本使用资金发生时的长桥参考汇率观察保存三币种可用值、来源和时间。历史补录只重算派生结果，不修改日初基准、每日趋势观测或正式日结，也不补造资产历史。

## 后果

2026-09-18 调整：总览与收益分析页的当前累计净投入、组合投资盈亏先按 USD 计算，再按当前长桥参考汇率折算为展示币种，注明“按当前汇率折算”。历史账本折算值、趋势观测和区间收益仍使用原有历史口径，不回写；缺少 USD 本金或当前目标币种汇率时仍不可计算。

- 用户可以可信地区分资产变化、本金变化与投资盈亏。
- 产品不需要获取交易流水、银行流水、平台充值提现或执行任何资金动作。
- 未有完整资产端点的历史不能生成收益结论；趋势图可以连接相邻真实观测，但缺失日期仍不生成金额或收益端点。
- 备份必须包含账本与汇率观察，同时继续排除凭证。

# 总资产趋势图采用 Recharts

日期：2026-07-31
状态：已采用

## 决策

总资产趋势图采用 Recharts 实现 A+B 设计：主摘要显示当天每日趋势观测金额和相较昨日的变化；折线没有状态圆点，缺失日保留为空值并在视觉上连接相邻真实观测。来源趋势与收益分析趋势遵循相同规则。

## 不可改变的契约

- 输入仍是连续上海自然日的观测序列；`amount: null` 是缺失日，不能补零或生成插值金额，折线仅跨过空值连接已有观测。
- 只有今天和昨天均为完整估值时才显示“较昨日”金额；缺少任一日期、不完整或过期都显示“数据不足”，不能回退为最近观测。
- 不完整、过期、未估值和缺失日期继续以文字说明表达；总览省略图下的覆盖统计，保留估值异常、空态和 tooltip 状态，呈现规则见[页面模式](../design-system/patterns.md#金融信息与隐私)。它们不能作为区间资产变动端点。
- 隐藏敏感信息、无历史、无可用金额、趋势区间、每日明细分页与移动端展开行为维持不变。
- Recharts 只接收用于绘制的 `number`；金额展示和业务计算继续使用 decimal 工具。

## 视觉与可访问性

- 使用现有 Vibe token：黑白单色、1px 发丝线、无阴影、无渐变。红色不用于趋势线装饰。
- `connectNulls={true}`、`dot={false}`、`activeDot={false}`；缺失事实继续由文字说明表达，不在折点上堆叠状态。
- Recharts 的无障碍层保留图表焦点与方向键 tooltip；来源趋势仍保留可见图像名称，异常事实由文字说明提供。

## 验收

按 [页面模式](../design-system/patterns.md#页面验收) 检查受影响的趋势入口，覆盖昨日比较、缺失日不补值、隐私隐藏、窄屏布局、键盘焦点与方向键 tooltip。执行范围遵守 [测试纪律](../../AGENTS.md#测试纪律)，历史验收从 Git 查询。

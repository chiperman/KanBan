# 独立来源的投资历史与收益曲线

日期：2026-09-29

修订：2026-10-18，仅手工资产允许维护手动记录，并统一录入入口。

状态：历史原件、身份校验与原币种原则继续采用；来源持有本金、独立收益及仅手工来源维护资金的规则由 [ADR-0007](0007-unify-investment-books.md) 替代（2026-10-18）。以下保留原决策背景。

## 背景

来源资产余额相对首次观测的变化包含资金进出，不能代表相对本金的收益。A 股与长桥是独立账户，外部记账数据必须按来源身份导入。

## 决策

- 来源投资历史独立保存外部账户身份、原始记录编号、日期、币种、资产金额和资金进出。期初本金须有明确依据，并与外部净投入、期末资产及累计盈亏对账。
- 导入只绑定身份核对后的手工来源或长桥账户；重复记录幂等，账户身份或已有导入记录冲突时拒绝静默覆盖。不自动写入 ADR-0004 的组合资金账本，不重写自动账户的当前快照或日结。
- 来源详情提供收益率曲线与累计收益曲线。累计收益为当天资产减截至当天净投入；收益率沿用按资金发生日加权的 Modified Dietz，标明记账以来累计、不年化。区间选择只筛选日期，不把累计本金重置为区间初余额。
- 历史收益使用账本原币种；缺少资产观测时不生成收益端点，不使用当前汇率伪造历史。同日资产金额按照所有者的明确选择，采用外部导入值，其次为本地手动记录，最后为自动观测；各自独有日期合并保留。
- 仅手工资产来源支持新增、编辑和删除手动记录，详情页统一提供「添加记录」入口，按类型录入资产总额、期初本金、投入或取出。新资产总额沿用每日余额记录通道，同日保存更新已有总额，最新记录更新当前金额；期初本金与资金进出独立存储，不改变当前金额，允许同日多笔资金进出，通过记录 ID 保证提交幂等。
- 自动来源保留刷新入口，页面、命令接口与持久化均拒绝手动记账的新增、编辑和删除；已有手动记账记录保留只读并可随备份恢复，外部历史导入能力保留。既有投资金额记录与每日余额记录不迁移、不改变历史计算优先级。
- 缺少外部完整历史的账户需要明确期初本金才能计算收益；从首笔投入前开始记账时，期初本金填零，首笔投入只计算一次。已有外部期初事实时不得再增设本地期初本金。不同币种不得直接相加。
- 来源详情统一展示两种收益曲线。缺少本金时说明数据不足，同时保留资产金额趋势，避免把余额变化作为收益率。最新自动余额只用其实际同步日作为今天的端点，不倒填历史。
- 原始历史随业务备份往返，恢复缺少该字段的旧备份时须明确确认丢弃。

## 后果

来源本金不会混入其他账户或被重复计入组合。外部平台采用不同收益率算法时，金额可以对账，但不声称收益率数值完全相同。

## 已确认的产品边界

- 这是本地优先、单所有者、只读的个人资产看板，不是个人主页、内容发布产品、交易平台、团队看板或完整个人财务系统。
- 未认证首页只显示所有者登录入口；不展示资产卡片、资产布局、来源身份、金额、虚构演示资产或设计化占位。
- 重构目标是认证后提供总览、资产与持仓、收益分析、资产来源和设置与安全；数据健康作为资产来源下的诊断入口。
- 身份、Now、链接、Markdown、普通内容卡片、公开/私密访问级别、发布/撤回、公开分享和受限卡片功能已经删除。
- 已支持的资产来源：长桥、Binance、OKX、Bitget、Ethereum 观察钱包和 BNB Smart Chain 观察钱包。
- Base、Arbitrum 与 Solana 不在首版范围；对应 Ticket 已标记为 `wontfix`，未来有真实使用需求时重新定义。
- 不实现交易、划转、提现、签名、钱包连接、私钥或助记词收集、普通合约仓位、杠杆、DeFi、NFT、多用户或公开注册；Bitget 仅额外读取平台聚合的合约交易机器人账户权益，不读取订单或执行交易。
- 初始投入、外部入金与外部出金是本机账本记录，不会发起或导入真实资金操作；平台间转账、买卖、换汇和调仓不影响组合级本金。

## 当前界面与数据模型

- 根页面有两个互斥状态：锁定登录页与已认证资产看板。
- 运行时卡片模型只包含资产卡片；持久化字段为 `assetCards`。
- 读取旧数据时保留有效资产卡片并迁移旧受限资产记录；旧身份、Now、链接、Markdown 和公开内容被丢弃。
- 资产卡片支持排序、1/2/3 格宽度、内容自适应高度、强制换行和隐藏。
- 隐藏不停止同步；断开删除凭证并停止同步但保留快照；永久删除需要第二次确认。
- Binance、OKX 与 Bitget 资产卡片使用统一产品覆盖结构；OKX 与 Bitget 对尚未接入或无法公开读取的产品明确显示“统计不完整”，不会推断为零资产。

## 视觉回归结论

- 页面采用 Nothing 风格的三层结构：总资产为唯一主视觉，资产来源为次级模块，时间、状态和主题为系统信息。
- 标题与正文使用 Space Grotesk，标签和数据使用 Space Mono；Doto 只用于关键状态与英雄数字。
- 字体变量挂在根元素，浏览器计算结果已确认三套字体真实生效，不允许仅凭声明判断字体验收通过。
- 总资产使用点阵英雄数字和分配比例仪表；来源卡片使用提供方代码、状态灯、12 段估值完整度和持仓编号。
- 深色与浅色主题使用相同的信息层级；状态同时以文字、符号和颜色表达。
- 桌面、中屏和手机分别使用三列、两列和单列资产布局，不应横向溢出。
- 锁定页使用非对称开放构图，不模拟或泄露资产布局；备用登录未配置时只显示 Passkey。

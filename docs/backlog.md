- 差异：[CONTEXT](../CONTEXT.md) 的“每日趋势观测”要求自动来源同一批次全部成功；[RefreshObservationRecorder](../src/server/refresh-observation-recorder.ts) 当前允许至少一次成功、没有 `superseded` 且来源集合一致时记录观测，再按完整性与状态判断基准写入资格。
- 下一步：结合当前需求、提交历史及部分失败相关测试核定规则，同步合同与实现。不能仅按旧规格恢复全成功门槛，也不能因实现已存在就认定口径获确认。
- 完成条件：整批成功、部分失败与来源集合变化时的观测和基准资格有一致合同及相应验证证据。

### 正式日结新增市场发现

- 差异：[日结执行器](../src/server/formal-daily-settlement.ts) 在采集前从持久化实时快照判断市场与窗口；当次采集发现新市场后会重新锚定，但不保存该发现供后续调度使用。
- 下一步：核定独立的市场发现或持久化证据方案，覆盖连续调度和 CLI 重启。保持正式日结与实时快照隔离、休市日语义及禁止后续价格补造历史，避免每次调度无条件全量估值。
- 完成条件：新增市场在后续运行中仍可参与窗口判断，且不会错用后续实时价格或漏记应采窗口；按核定方案验证。

### 卡片、空态与字段密度核定

- 卡片：通用 `.card` 的有边框表面、总览玻璃卡及透明模块并存。先核对页面用途与信息层级，再决定哪些是允许的材质分类；不一刀切去边框或添加悬停位移。
- 空态：当前上下细线变体与上游虚线加点阵配方不同。先确定采用关系，再决定是否组件化；不因上游有样例就重做现有页面。
- 字段：`.vibe-field__input` 为至少 48px / 16px，选择触发器为至少 44px / 13px。需核定同表单中的密度与角色，保留触控和文字可读性。
- 完成条件：上述取舍有明确合同，必要改动经过对应页面验证，同步主题文档后移除本项。

### 存量样式与守门基线收敛

- 非标准断点、遗留或被覆盖的字体/圆角声明需沿调用和层叠关系逐项复核；已删除的选择器、已统一的配色和字号不再重复列入整改。
- `box-shadow` 与 `!important` 先区分投影、焦点提示、几何绘制和减弱动效覆盖。保护焦点、SVG 遮罩与已有隐私纹理，不按计数机械删除。
- [lint 基线](../scripts/design-system/token-lint-baseline.json) 中已有可收紧的过期签名；先确认实际修复，再更新基线，不放宽规则消除报错。
- 完成条件：本次选定的存量有源码与影响证据，必要修复通过相关门禁。没有单独媒体查询的 CSS 若已受全局减弱动效覆盖，不列为缺陷。

# 调研资料阅读规则

本目录保存技术调研和特定日期的实现观察，不作为现行产品合同。文中的“当前”“已接入”“未实现”和外部 API 能力，均按其调研或最后验证日期解读。

- 实施前先读 [现行文档入口](../README.md)，再核对相关源码；涉及外部接口时重新核对官方资料，不能沿用旧调研的可用性结论。
- 实际采用的长期规则提炼到所属现行合同，其他文档链接引用；调研保留背景、选择依据和证据，不维护第二套“当前规则”。
- 新复核追加日期、范围与结论；旧真实账户、外部接口和测试结果不自动成为本次验收。

[资产刷新生命周期](asset-refresh-lifecycle.md) 是 2026-08-26 的实现观察，不能按文件名认定其持续反映当前实现。今日源码入口见 [当前能力与源码导航](../current-baseline.md#其他实现入口)。

# Triage 标签

相关技能使用五类标准 triage 角色。本文件将这些角色映射到本仓库 Issue 跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估此 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由无人值守 Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提及某个角色（例如“应用可由无人值守 Agent 处理的 triage 标签”）时，使用上表中对应的标签字符串。

如需匹配实际使用的词汇，请编辑右侧“本仓库跟踪器中的标签”列。

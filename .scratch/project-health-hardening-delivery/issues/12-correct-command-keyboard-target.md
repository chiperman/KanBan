# 12: 修正命令菜单键盘目标

**What to build:** 键盘操作命令菜单时，Enter 执行实际聚焦的按钮或搜索高亮项，关闭按钮和中文输入法不会误触其他命令。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Phase:** 本迭代处理
**Priority:** 中
**Parent:** 原项目健康度规格 · 08 — 使命令菜单执行正确的键盘目标

**Approval:** 2026-09-10 所有者确认 16 个执行切片及阻塞关系；本次授权仅为发布 Ticket，未授权代码实施。

## 验收标准

- [ ] 先用浏览器复现 Tab 聚焦关闭按钮后 Enter 的问题，修复后只关闭菜单且不执行命令。
- [ ] Tab 聚焦命令按钮后 Enter 仅执行该按钮一次；搜索输入的 Enter 执行当前高亮命令。
- [ ] 方向键、Tab、Escape、空结果和中文组合输入均正确，不出现重复或误执行。
- [ ] 关闭后焦点回到合理触发位置，既有样式和布局保持。

审查发现容器拦截子元素冒泡的 Enter 并执行高亮项；代码路径已确认，需先补浏览器复现。

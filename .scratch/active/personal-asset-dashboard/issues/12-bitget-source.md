# 12 — Bitget 只读资产来源

**What to build:** 让所有者通过只读 Bitget API 凭证查看现货、资金、Earn 和合约交易机器人聚合权益，并按 Bitget 原生行情或账户估值纳入总资产及历史流程，同时严格排除任何写权限、普通合约仓位、杠杆和借贷产品。

**Blocked by:** 07 — 估值与资产分布真实性；08 — 自动刷新与过期数据

**Status:** resolved

**Adjusted by:** `.scratch/archive/asset-refresh-redesign/spec.md`

- [x] Bitget 使用统一的来源添加、权限验证、范围预览和原子保存流程。
- [x] 只接受 Read-Only 权限；具备交易、转账或提现权限的凭证被拒绝。
- [x] API Key、Secret 和 Passphrase 仅存于服务端安全存储。
- [x] 同步包含现货、资金、Earn 和 `futures` 合约交易机器人聚合权益；机器人使用专用只读账户端点，不读取订单或普通合约仓位。
- [x] 排除普通合约仓位、杠杆、借贷、现货机器人及其他约定外账户。
- [x] Bitget 持仓优先使用 Bitget 原生行情或账户估值，并保存价格来源与时间。
- [x] 平台缺少可靠价格时遵循未估值资产规则，不默认按零处理。
- [x] Bitget 卡片显示来源总额、前五持仓和完整可排序详情，并接入刷新、过期数据及快照流程。
- [x] 官方响应样本覆盖账户类型、币种精度、分页、权限和错误映射，不在自动测试中调用真实账户。

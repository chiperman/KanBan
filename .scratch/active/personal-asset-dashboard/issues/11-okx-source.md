# 11 — OKX 只读资产来源

**What to build:** 让所有者通过只读 OKX API 凭证查看现货、资金和 Earn 资产，并按 OKX 原生行情纳入总资产及历史流程，同时严格排除任何写权限和杠杆产品。

**Blocked by:** 07 — 估值与资产分布真实性；08 — 自动刷新与过期数据

**Status:** resolved

**Adjusted by:** `.scratch/archive/asset-refresh-redesign/spec.md`

- [x] OKX 使用统一的来源添加、权限验证、范围预览和原子保存流程。
- [x] 只接受 Read 权限；具备 Trade、划转或 Withdraw 权限的凭证被拒绝。
- [x] API Key、Secret 和 Passphrase 仅存于服务端安全存储。
- [x] 同步包含现货、资金和 Earn 资产，并排除合约、保证金、杠杆、借贷及其他约定外账户。
- [x] OKX 持仓优先使用 OKX 原生行情或账户估值，并保存价格来源与时间。
- [x] 平台缺少可靠价格时遵循未估值资产规则，不默认按零处理。
- [x] OKX 卡片显示来源总额、前五持仓和完整可排序详情，并接入刷新、过期数据及快照流程。
- [x] 官方响应样本覆盖账户模式、币种精度、分页、权限和错误映射，不在自动测试中调用真实账户。

# 24 — 锁定页与预置页可读性修正

**What to build:** 在保留 Nothing 视觉语言和隐私边界的前提下，修正锁定页与所有者预置页过小、对比度不足和中文标题碎片化的问题。

**Blocked by:** None

**Priority:** P1

**Status:** resolved

- [x] 锁定页的辅助标签、状态、信任说明和页脚文字满足正常文字可读性要求，不再使用 `9px + #666/黑色` 的低对比组合。
- [x] 重要安全信息不依赖极小英文标签传达；中文主信息在桌面和手机上均可快速理解。
- [x] 所有者预置页在桌面宽度下提供合理的正文宽度，标题和说明不被切成连续的两三个汉字短行。
- [x] 主操作、错误状态、焦点轮廓和键盘顺序保持清晰；现有 44px 最小点击高度不得回退。
- [x] 深色、浅色以及 1280px、800px、390px 三种宽度完成真实浏览器视觉检查，无横向溢出或内容截断。
- [x] 自动化检查覆盖主要文字计算样式、焦点可见性、主操作尺寸和手机端无横向溢出。

## Nothing Design 约束

- Doto 仅用于 36px 以上的 `LOCKED` / `SETUP` 点阵主状态，不用于正文、标签或时间仪表；中文安全标题使用 Space Grotesk，机械标签和时钟使用 Space Mono。
- 正常辅助文字使用 `12px` 及 `--ink-secondary`，明暗主题均满足正常文字对比度；`--ink-muted` 只保留给非必要装饰信息。
- 保留黑白画布、非对称留白、扁平分隔线、胶囊操作和点阵纹理；不新增阴影、渐变、图标或额外强调色。
- 中文标题和安全说明优先于英文仪表标签，Nothing 表达不取代可理解性与可访问性。

## 审查证据

- 2026-07-27 真实浏览器计算样式：多处辅助文字为 9px、`rgb(102, 102, 102)`、黑色背景，对比度约 `3.66:1`。
- 390px 锁定页无横向溢出，主按钮高度为 44px；这些已通过项需要保持。
- 桌面预置页正文栏过窄，“预置唯一所有者的 Passkey”被切成多个短行，页面右侧存在大面积无信息空间。

## 评论

- 本 Ticket 是可读性修正，不重新设计锁定页，也不引入与现有设计系统冲突的新视觉语言。
- 2026-07-28：按 Nothing Design 完成锁定页与预置页可读性修正。锁定页增加可见中文主标题，辅助标签、状态、信任说明和页脚统一为至少 12px 的正常对比文字；预置页保持 760px 桌面正文栏和两行以内的平衡标题。
- 2026-07-28：新增 `locked-setup-accessibility.spec.ts`，TDD 红灯确认中文锁定标题缺失和 9px 标签问题，修正后 8/8 通过；覆盖明暗主题、1280/800/390 三宽度、文字计算样式与对比度、焦点轮廓、键盘顺序、44px 主操作、错误反馈及横向溢出。
- 2026-07-28：使用真实 Chromium 逐页检查预置态和已预置锁定态，明暗主题及 1280/800/390 三宽度均无横向溢出或内容截断。最终全量测试 134 项中 131 项通过；OKX 用例的瞬时 `page.reload()` 中断单独重跑 1/1 通过，稳定剩余 2 项为既有隐私断言把锁定页上海系统时钟与固定资产时间字符串混同。本 Ticket 未改动时钟数据、逻辑或隐私边界，未扩大范围处理。

# 30 — 忽略观察钱包未识别代币

**What to build:** 让所有者把观察钱包中的空投垃圾、貔貅或其他非投资代币按链与合约地址可恢复地忽略，避免它们占据持仓明细并持续造成无意义的未估值警告。

**Blocked by:** 07 — 估值与资产分布真实性；13 — Ethereum 与 BNB Smart Chain 观察钱包

**Status:** resolved

## 领域边界

- “未识别代币”是观察钱包中有正余额、无可靠参考价格且尚未由所有者确认的 ERC-20/BEP-20；缺价本身不能证明它是垃圾代币。
- “忽略代币”必须由所有者按 `chain ID + contract address` 明确确认，不按 symbol、名称、数量或余额阈值匹配。
- 忽略只改变个人资产看板的投资资产范围，不执行转账、授权、出售或其他链上操作。
- 忽略规则可恢复；普通未估值资产继续保留数量并使总资产标明不完整。

## 测试 seam

- 所有者浏览器边界：认证后的 EVM 卡片默认收起未识别代币，可以忽略并恢复。
- 资产估值边界：只有所有者已忽略的合约不再进入持仓数量、未估值数量、资产分布和总额完整性；普通缺价资产不受影响。
- 业务数据持久化边界：忽略规则随来源保存、备份和恢复，永久删除来源时一并删除。

## 验收标准

- [x] EVM 卡片默认不在持仓摘要和明细表展开未识别代币，并明确显示收起数量。
- [x] 所有者可以查看未识别代币的 symbol、数量与完整合约地址，单个或批量忽略。
- [x] 忽略规则使用来源资产标识中的链 ID 与合约地址，不按名称或 symbol 误匹配。
- [x] 已忽略代币不计入卡片持仓数、未估值数、资产分布或总额完整性。
- [x] 所有者可以查看并恢复已忽略代币；恢复后它重新成为未识别/未估值资产。
- [x] 忽略操作只允许已认证所有者调用，并拒绝非 EVM 来源、原生币及不存在的合约。
- [x] 忽略规则持久保存；余额和价格刷新不会丢失规则。
- [x] 桌面和手机宽度下入口、列表、按钮、键盘焦点与状态反馈可用。

## 答案

- 未识别 EVM 代币默认从持仓摘要和明细收起，但原始链上余额仍保留在来源快照中。
- 所有者可按 `evm:<chainId>:<contractAddress>` 查看完整合约与数量，并选择保留、忽略、批量忽略或恢复；规则不使用 symbol、名称或余额阈值。
- 已忽略代币从投资资产范围、持仓数、未估值数、分布、来源总额和总资产完整性中排除；已保留代币继续正常显示并保留未估值提示。
- 忽略与保留规则随来源写入 SQLite schema v8，支持旧 schema 自动迁移、重启持久化、备份恢复和来源永久删除。
- 已分类合约刷新后即使获得价格，仍可恢复或重新分类；新的有价代币不能借此接口首次加入忽略名单。

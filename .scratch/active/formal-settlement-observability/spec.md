# 正式日结状态与执行可观测性

首页区分缺历史、完整、不完整、错过窗口；展示真实交易日与金额，隐私模式隐藏金额与持仓诊断。实时资产和近7日趋势不依赖正式日结。

最近执行记录与日结质量分离：开始/完成时间、outcome、固定安全原因码、日结质量。复用 SQLite，只保存最新执行，旧执行不得覆盖新执行，不进入业务备份。顶层异常也记录，存储失败安全报错。

设置只读显示本地 launchd 配置/加载状态与最近执行。区分缺配置、未加载、已加载、查询失败、非macOS；不推断外部调度、当前采集健康或下次时间。页面不运行采集或安装。页面与CLI统一 KANBAN_DATA_DIR。

## 用户已指定的验收边界
- 运行器及临时SQLite：等待、异常、持久化、并发、质量、错误码、备份排除。
- 调度端口：各类探测结果，旧成功不改变当前状态。
- 隔离浏览器：登录、空态、历史日期、完整/不完整/错过、隐私、设置、移动宽度、demo隔离。
- typecheck、相关单测、隔离构建；不启动真实任务、不写真实日结、不停止用户服务。

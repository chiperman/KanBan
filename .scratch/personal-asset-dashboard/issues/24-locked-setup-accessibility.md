# 24 — 锁定页与预置页可读性修正

**What to build:** 在保留 Nothing 视觉语言和隐私边界的前提下，修正锁定页与所有者预置页过小、对比度不足和中文标题碎片化的问题。

**Blocked by:** None

**Priority:** P1

**Status:** ready-for-agent

- [ ] 锁定页的辅助标签、状态、信任说明和页脚文字满足正常文字可读性要求，不再使用 `9px + #666/黑色` 的低对比组合。
- [ ] 重要安全信息不依赖极小英文标签传达；中文主信息在桌面和手机上均可快速理解。
- [ ] 所有者预置页在桌面宽度下提供合理的正文宽度，标题和说明不被切成连续的两三个汉字短行。
- [ ] 主操作、错误状态、焦点轮廓和键盘顺序保持清晰；现有 44px 最小点击高度不得回退。
- [ ] 深色、浅色以及 1280px、800px、390px 三种宽度完成真实浏览器视觉检查，无横向溢出或内容截断。
- [ ] 自动化检查覆盖主要文字计算样式、焦点可见性、主操作尺寸和手机端无横向溢出。

## 审查证据

- 2026-07-27 真实浏览器计算样式：多处辅助文字为 9px、`rgb(102, 102, 102)`、黑色背景，对比度约 `3.66:1`。
- 390px 锁定页无横向溢出，主按钮高度为 44px；这些已通过项需要保持。
- 桌面预置页正文栏过窄，“预置唯一所有者的 Passkey”被切成多个短行，页面右侧存在大面积无信息空间。

## 评论

- 本 Ticket 是可读性修正，不重新设计锁定页，也不引入与现有设计系统冲突的新视觉语言。

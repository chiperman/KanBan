# 03 — 公开内容编辑与访问级别

**What to build:** 让所有者在登录后创建和维护公开主页内容，并明确控制普通卡片的公开或私密访问级别。访客只看到主动发布的内容，所有编辑入口始终属于所有者。

**Blocked by:** 02 — 所有者登录与受限卡片隔离

**Status:** ready-for-agent

- [ ] 所有者可以编辑头像、昵称和一句话介绍组成的身份卡片。
- [ ] 所有者可以编辑 Now 卡片和包含外部链接的链接卡片。
- [ ] 所有者可以创建、编辑和删除 Markdown 自定义卡片，无需完整块编辑器。
- [ ] 新建普通卡片默认为私密，只有所有者主动发布后才对访客显示真实内容。
- [ ] 私密普通卡片在访客状态下按受限卡片规则呈现，不泄露其真实正文。
- [ ] 所有者可以把已公开的普通卡片改回私密，刷新后访客立即失去访问权。
- [ ] 资产类型卡片的访问级别始终为私密，任何客户端或服务端请求都不能将其发布。
- [ ] 访客看不到编辑、发布、删除或访问级别控制入口。
- [ ] 浏览器级测试证明公开内容与私密内容在访客和所有者视图中正确分离。

# 31 — 手工资产记录

**What to build:** 让所有者先为无法接入的资产组创建独立资产来源，例如 `A股`，再在对应卡片内记录 `100000 / CNY`；该资产组不维护持仓或流水。

**Blocked by:** 21 — SQLite 业务数据持久化；29 — 单资产来源刷新

**Status:** resolved

## 领域边界

- 手工资产记录是资产来源，但不使用外部凭证，也不进行自动或手动刷新。
- 资产类别属于手工资产来源设置，可在来源管理中修改；未分类不影响总额估值完整性。
- 创建手工来源只保存名称并生成独立卡片；未添加首条数据前不得作为 0 计入总资产、日初基准或趋势。
- 每个手工资产组在同一上海自然日最多有一条记录；可新增、编辑或删除任意过去或当天的本资产组金额，不生成重复历史，也不改写其他来源。
- 当前卡片总额取记录日期最新的一条；删除最新记录后回退到上一条，删除最后一条后恢复未录入状态。
- 编辑或删除过去日期只更新该来源的每日基准/趋势来源行；没有既有过去日初基准时，不伪造其他来源的历史数据。
- 手工记录计入总资产、今日资产变动和趋势；不存在可靠汇率时，只在同币种计价视图显示金额，不能虚构换算。
- 手工资产可在卡片内添加、编辑或删除按日期保存的总额，也可管理名称或永久删除数据；不支持断开。

## 测试 seam

- 所有者浏览器边界：从“添加资产来源”创建 `A股`，在该卡片内新增过去日期记录、编辑并删除；删除最新记录后卡片回退到上一日金额。
- API 边界：未认证、非法金额或日期、未来日期、非手工来源编辑、手工来源刷新和断开均被拒绝。
- 存储边界：SQLite v9 升级后回填既有手工快照；文件与内存存储可维护每个来源每天一条记录及对应来源观测。

## 验收标准

- [x] 所有者可从“添加资产来源”创建多个独立手工资产来源，名称与金额记录分离。
- [x] 所有者可在对应卡片内添加任意过去或当天的 USD/CNY/HKD 总额。
- [x] 手工资产卡片只展示总额、趋势与最后记录时间，不展示持仓明细或刷新入口。
- [x] 来源管理可设置资产类别，手工来源总额直接归入所选类别，不再误报为未解释差额。
- [x] 历史列表可编辑或删除任意日期；同一资产组每天没有重复记录，删除最新值会回退。
- [x] 手工资产计入总资产、今日资产变动和趋势；编辑/删除只重算本来源对应日期，缺少汇率时不伪造折算。
- [x] 手工资产不需要凭证，不支持刷新或断开；永久删除仍需二次确认。
- [x] 非所有者、非法输入、未来日期和非手工来源编辑请求被拒绝。

## 答案

- 手工资产作为无凭证的资产来源先保存名称并生成独立卡片；总额与原始币种只在该卡片内保存，不保存持仓、成本或交易流水。
- 未填首条数据的手工来源显式显示“尚未记录数据”，不伪造 0，也不计入总资产或每日观测。
- 同一手工资产组在同一上海自然日只保留一条来源观测；当天再次保存会覆盖该资产组的金额，并重新汇总总资产和趋势。
- 默认 USD/HKD 视图缺少可靠汇率时明确显示“无法折算”；切换到原始币种 CNY 时可正常显示并参与趋势，不会虚构汇率。

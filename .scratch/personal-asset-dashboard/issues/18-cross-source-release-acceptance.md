# 18 — 跨来源总资产集成与发布验收

**What to build:** 把所有已完成切片组合为可交付的首版个人终端。所有者能够同时查看证券、中心化平台和观察钱包资产；访客只看到安全公开主页；跨来源估值、失败隔离、历史趋势和视觉体验经过完整验证。

**Blocked by:** 09 — 每日资产快照与今日资产变动；10 — Binance 只读资产来源；11 — OKX 只读资产来源；12 — Bitget 只读资产来源；13 — Ethereum 与 BNB Smart Chain 观察钱包；16 — 隐藏、断开与删除资产来源；17 — 命令菜单与完整视觉语言

**Status:** ready-for-agent

- [ ] 长桥、Binance、OKX、Bitget、Ethereum 与 BNB Smart Chain 可以同时存在，并形成正确的总资产与分布。
- [ ] 来源原生价格差异、稳定币实际价格、CNY 切换、未估值资产和过期数据可以在同一组合场景中正确表达。
- [ ] 一个或多个来源失败时，成功来源继续更新，总资产明确标示数据状态且任何来源都不会被误置为零。
- [ ] 公开主页、受限卡片、所有者内容、资产详情、布局编辑、锁定和恢复流程形成连续完整体验。
- [ ] 自动化浏览器测试覆盖核心访客与所有者旅程，并检查 HTML、接口响应和网络流量不存在未授权敏感数据。
- [ ] 每个真实平台验收前先确认凭证为只读；无法证明最小权限时停止，不连接或测试该凭证。
- [ ] 使用可用的真实只读账户分别完成人工连接、同步、刷新和断开验收，且不执行任何写操作。
- [ ] 在浅色和深色主题、桌面、中屏和手机宽度完成最终视觉验收。
- [ ] 首版不存在交易、划转、提现、签名、通知、合约、杠杆、DeFi、NFT、多用户或公开注册入口。
- [ ] 所有自动化检查、真实来源人工验收和视觉验收分别记录结果，不把其中一类成功冒充其他验收已完成。

# 08 — 自动刷新与过期数据

**What to build:** 让资产数据在页面使用期间自动更新，并在外部来源失败时继续如实展示最后成功状态。任何同步错误都不能把真实资产变成零，也不能阻塞其他来源更新。

**Blocked by:** 06 — 长桥首个资产来源闭环

**Status:** resolved

- [x] 打开所有者页面时立即触发一次资产同步。
- [x] 页面可见时行情每 30 秒刷新，余额和持仓每 5 分钟刷新。
- [x] 页面隐藏时暂停定时刷新，恢复可见后按需要重新同步。
- [x] 所有者可以手动刷新，并看到进行中、成功或失败状态。
- [x] 某个来源同步失败时保留最后成功数据、最后更新时间和已知总额，不显示为零。
- [x] 失败来源明确标记为过期数据，总资产同时标明包含过期数据。
- [x] 一个来源失败不会阻止其他来源成功提交新数据。
- [x] 手动或自动同步失败都不能覆盖最后一次成功快照或持仓。
- [x] 自动化测试使用可控时间和确定性来源替身验证调度、页面可见性和部分失败。

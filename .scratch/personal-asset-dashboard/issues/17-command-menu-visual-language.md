# 17 — 命令菜单与完整视觉语言

**What to build:** 完成个人终端的快捷操作和整体视觉表达。所有者可以通过 Command-K 快速导航、刷新和锁定，同时页面在浅色与深色主题中一致融合 Efferd、Nothing 和 Bloomberg Terminal 的设计职责。

**Blocked by:** 04 — 卡片编排与响应式布局；05 — 恢复认证与会话锁定；08 — 自动刷新与过期数据

**Status:** resolved

- [x] `⌘K` 可以打开命令菜单，且 Windows/Linux 等非 macOS 环境提供等价快捷键。
- [x] 命令菜单可以搜索并跳转到可见资产卡片、触发手动刷新和主动锁定。
- [x] 所有命令均有完整的鼠标或触控入口，不要求键盘优先使用。
- [x] Efferd 风格负责卡片层级、留白和现代 Dashboard 结构，页面不照搬单一模板。
- [x] Nothing 点阵或像素元素只用于标题、图标、状态和装饰强调，不降低正文和数据可读性。
- [x] Bloomberg Terminal 语言用于等宽数字、紧凑状态和 ASCII 分隔，不实现终端命令输入。
- [x] 浅色、深色及系统主题在桌面、中屏和手机宽度下保持一致的信息层级。
- [x] 状态颜色、文字与图标不会只依赖颜色表达过期、失败或未估值状态。
- [x] 完成两种主题、三种代表性宽度的人工或截图视觉验收。

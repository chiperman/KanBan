# 05 — 恢复认证与会话锁定

**What to build:** 为唯一所有者补全安全的恢复登录和锁定流程，使 Passkey 不可用时仍能恢复访问，同时让无人看管或已关闭的浏览器不会持续暴露敏感信息。

**Blocked by:** 02 — 所有者登录与受限卡片隔离

**Status:** resolved

**Superseded by:** 19 — 锁定后返回所有者登录页，不再返回公开主页或受限卡片布局。

- [x] 所有者可以通过邮箱、强密码和 TOTP 完成备用恢复认证。
- [x] 未配置备用登录时，锁定页不显示无法使用的备用登录入口。
- [x] 配置页明确说明邮箱只作为本机登录标识，不发送验证邮件。
- [x] 恢复流程不提供社交登录、短信验证码或公开注册。
- [x] 未完成 TOTP 验证的恢复会话不能访问任何敏感信息。
- [x] 连续 30 分钟无所有者操作后，敏感会话自动锁定并恢复公开主页状态。
- [x] 关闭浏览器后再次打开时，敏感会话不自动恢复。
- [x] 所有者可以通过页面按钮或命令入口主动锁定，并立即隐藏敏感内容。
- [x] 锁定后再次点击受限卡片可以使用 Passkey 快速解锁。
- [x] 自动化测试使用可控时间验证超时，不依赖真实等待。

## 评论

2026-07-27 体验修正：

- 用户未配置邮箱、密码和 TOTP 时，锁定页只显示 Passkey 登录。
- 所有者登录后可通过“配置备用登录”创建备用凭证；配置完成后，锁定页才显示“使用备用方式登录”。
- 用户界面不再使用含义模糊的“恢复认证”文案，并明确邮箱不会收到验证邮件。

# 13 — Ethereum 观察钱包与参考定价

**What to build:** 让所有者只凭公开 Ethereum 地址添加观察钱包，读取 ETH 与 ERC-20 余额，并通过独立参考价格纳入总资产。整个流程保持纯读取，不连接钱包、不签名、不接触任何密钥。

**Blocked by:** 07 — 估值与资产分布真实性；08 — 自动刷新与过期数据

**Status:** ready-for-agent

- [ ] 所有者可以通过统一来源流程添加并预览一个或多个公开 Ethereum 地址。
- [ ] 系统只接受公开地址，不提供粘贴助记词、私钥、MPC 材料或连接钱包的入口。
- [ ] 同步读取 ETH 和 ERC-20 余额，并以链和合约地址标识代币，不仅依赖符号。
- [ ] CoinGecko 作为观察钱包初始参考价格来源，价格结果记录来源与更新时间。
- [ ] 无可靠参考价格的代币按未估值资产显示，保留数量但不计入数值总额。
- [ ] NFT、质押、LP、借贷和其他 DeFi 仓位不进入结果。
- [ ] Ethereum 观察钱包卡片接入总资产、详情、刷新、过期数据和每日快照流程。
- [ ] 自动测试使用链上 RPC 与参考价格样本验证原生币、ERC-20、同名代币、空钱包和部分失败。

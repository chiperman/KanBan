# 16 — 隐藏、断开与删除资产来源

**What to build:** 让所有者安全管理资产来源生命周期，明确区分只影响布局的隐藏、停止授权但保留历史的断开，以及永久清除历史的数据删除。

**Blocked by:** 09 — 每日资产快照与今日资产变动

**Status:** done

- [x] 隐藏资产卡片只改变页面可见性，来源继续同步并继续计入总资产和快照。
- [x] 所有者可以重新显示隐藏卡片，期间累计的数据保持连续。
- [x] 断开来源会删除其只读凭证并停止后续同步，但保留来源配置的历史标识和已有快照。
- [x] 断开后不得再使用旧凭证发起任何平台请求。
- [x] 删除来源数据是与断开不同的独立操作，并明确说明将永久删除的内容。
- [x] 永久删除必须经过第二次确认，取消确认不会改变来源或历史。
- [x] 确认删除后，该来源及其全部持仓记录、同步记录和资产快照从所有视图移除。
- [x] 浏览器级测试覆盖隐藏、恢复显示、断开、取消删除和确认删除的完整行为。

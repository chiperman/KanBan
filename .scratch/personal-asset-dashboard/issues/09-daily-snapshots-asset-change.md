# 09 — 每日资产快照与今日资产变动

**What to build:** 从首次成功同步开始保存可信的每日资产快照，并把它们呈现为总资产及来源趋势。今日变化必须使用准确术语，不能把入金、出金或账户划转误称为投资收益。

**Blocked by:** 07 — 估值与资产分布真实性；08 — 自动刷新与过期数据

**Status:** resolved

- [x] 系统以 Asia/Shanghai 为唯一日期边界，并以北京时间 00:00 建立每日基准。
- [x] 每个自然日只生成一个有效日快照，重复同步不会产生重复日记录。
- [x] 历史从首次成功同步开始，不自动回填此前日期。
- [x] 总资产和各资产来源均可查看基于资产快照形成的历史趋势。
- [x] 总览显示“今日资产变动”，不显示未经交易流水校正的“当日盈亏”或“投资收益”。
- [x] 只有资产来源明确返回平台盈亏时，才在对应来源范围内展示该字段。
- [x] 同步失败或未估值资产不会被伪造成零值快照，趋势状态明确反映数据不完整性。
- [x] 自动化测试使用可控时间覆盖午夜边界、首次同步、同日幂等和跨日生成。

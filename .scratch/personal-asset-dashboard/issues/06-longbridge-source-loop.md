# 06 — 长桥首个资产来源闭环

**What to build:** 交付第一个真实、完整的只读资产来源。所有者通过 OAuth 2.0 Authorization Code + PKCE 安全授权长桥账户，预览并确认可读取范围，随后在私密资产卡片和详情面板中查看账户总额与证券、基金持仓；该闭环同时建立后续资产来源复用的共同边界。

**Blocked by:** 02 — 所有者登录与受限卡片隔离

**Status:** ready-for-human

- [x] 所有者可以从统一“添加资产来源”流程选择长桥并开始 OAuth 授权。
- [x] OAuth 只申请并只接受精确 `scope=6`；缺失、未知、附加 scope 或交易写权限 `scope=11` 均在读取和保存前拒绝。
- [x] 授权成功后先预览账户身份和可读取范围，只有确认后才保存资产来源。
- [x] 授权、验证或预览任一步失败时，不保存半成品来源或凭证。
- [x] Access Token 与 Refresh Token 只进入服务端加密安全存储，浏览器响应、HTML、日志和普通数据记录中均不包含凭证内容。
- [x] 生产数据访问严格只允许三个官方 REST GET：`/v1/asset/account`、`/v1/asset/stock`、`/v1/asset/fund`；不得接入行情、MCP、`longbridge` SDK、WebSocket 或任何交易接口。
- [x] 首次成功同步后以 `/v1/asset/account` 的 `net_assets` 显示长桥资产总额，并展示前五项持仓和最后更新时间；股票接口未提供可靠价格时保留数量并明确标记未估值，不伪造价格、市值或盈亏。
- [x] 点击长桥资产卡片可以查看全部持仓，并按市值、涨跌或名称排序。
- [x] 关闭详情面板后恢复此前页面位置。
- [x] 长桥资产卡片始终私密，访客只收到不含账户、代码、金额或时间戳的安全占位模型。
- [x] 30 秒统一价格周期对长桥执行零网络请求（包括不刷新 Token）；5 分钟持仓周期才执行上述三个 GET，并在失败时保留最后成功快照、标记过期。
- [x] 使用官方响应样本在浏览器级边界验证精度、币种、数量、成本、来源原生字段和刷新语义；测试证明没有订单请求、没有 Token 泄露，且不调用真实账户。

# 06 — 长桥首个资产来源闭环

**What to build:** 交付第一个真实、完整的只读资产来源。所有者通过 OAuth 2.0 Authorization Code + PKCE 安全授权长桥账户，预览并确认可读取范围，随后在私密资产卡片和详情面板中查看账户总额与证券、基金持仓；该闭环同时建立后续资产来源复用的共同边界。

**Blocked by:** 02 — 所有者登录与受限卡片隔离

**Status:** ready-for-human

- [x] 所有者可以从统一“添加资产来源”流程选择长桥并开始 OAuth 授权。
- [x] 私有官方 SDK 补丁固定请求并只接受 `account.read`；缺失、未知、附加 scope 或任何交易权限均在读取和保存前拒绝。
- [x] 授权成功后先预览账户身份和可读取范围，只有确认后才保存资产来源。
- [x] 授权、验证或预览任一步失败时，不保存半成品来源或凭证。
- [x] Access Token 与 Refresh Token 仅进入 macOS Keychain；浏览器响应、HTML、日志、普通数据记录及服务端加密 SecretStore 中均不包含凭证正文。
- [x] 生产数据只通过私有、只读的官方 Rust SDK 扩展读取账户、持仓和报价；不导出交易、划转、提现或订单接口。
- [x] 首次成功同步后以账户 `net_assets` 显示长桥资产总额，并展示前五项持仓、当前价、原始市值和最后更新时间；报价不可用时保留数量并明确标记未估值，不伪造价格、市值或盈亏。
- [x] 点击长桥资产卡片可以查看全部持仓，并按市值、涨跌或名称排序。
- [x] 关闭详情面板后恢复此前页面位置。
- [x] 未认证首页只显示所有者登录入口，不返回长桥账户、代码、金额、时间戳或资产占位。
- [x] 30 秒统一价格周期使用只读 SDK 拉取已有持仓的报价；5 分钟持仓周期刷新账户、持仓与报价。失败时保留最后成功快照、标记过期。
- [x] 使用官方响应样本在浏览器级边界验证精度、币种、数量、成本、来源原生字段和刷新语义；测试证明没有订单请求、没有 Token 泄露，且不调用真实账户。

## 评论

- 2026-07-27：按所有者确认改为统一 SDK OAuth + macOS Keychain。网页仍使用已注册的 `localhost:3000/api/asset-sources/longbridge/oauth/callback` 回调；PKCE verifier 与 Token 均留在原生模块/Keychain。实现已验证私有 OAuth 补丁、Keychain 存储命名空间、Node 原生加载、类型检查与既有浏览器回归；尚未以真实长桥账户完成授权与报价验收，故状态保持 `ready-for-human`。

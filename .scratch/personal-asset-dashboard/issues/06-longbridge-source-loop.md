# 06 — 长桥首个资产来源闭环

**What to build:** 交付第一个真实、完整的只读资产来源。所有者可以安全授权长桥账户，预览并确认可读取范围，随后在私密资产卡片和详情面板中查看账户总额与证券持仓；该闭环同时建立后续资产来源复用的共同边界。

**Blocked by:** 02 — 所有者登录与受限卡片隔离

**Status:** ready-for-agent

- [ ] 所有者可以从统一“添加资产来源”流程选择长桥并开始 OAuth 授权。
- [ ] 系统只接受行情、账户和持仓读取权限；检测到交易权限时拒绝连接并给出明确说明。
- [ ] 授权成功后先预览账户身份和可读取范围，只有确认后才保存资产来源。
- [ ] 授权、验证或预览任一步失败时，不保存半成品来源或凭证。
- [ ] 凭证只进入服务端安全存储，浏览器响应、日志和普通数据记录中均不包含凭证内容。
- [ ] 首次成功同步后显示长桥资产总额、市值最高的五项持仓和最后更新时间。
- [ ] 点击长桥资产卡片可以查看全部持仓，并按市值、涨跌或名称排序。
- [ ] 关闭详情面板后恢复此前页面位置。
- [ ] 长桥资产卡片始终私密，访客只收到不含账户、代码、金额或时间戳的安全占位模型。
- [ ] 使用官方响应样本验证分页、精度、币种、成本和平台盈亏字段映射，不在自动测试中调用真实账户。

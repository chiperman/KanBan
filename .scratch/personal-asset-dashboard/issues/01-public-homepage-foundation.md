# 01 — 公开主页与应用验证骨架

**What to build:** 建立可本地运行的个人终端最小纵向闭环。访客无需登录即可打开公开主页，看到稳定的卡片页面与基础主题；同时建立以真实浏览器驱动完整应用的首条自动化验证路径，为后续功能提供共同测试边界。

**Blocked by:** None — can start immediately

**Status:** resolved

**Superseded by:** 19 — 收口为纯私有资产看板。应用骨架、主题和浏览器测试 seam 保留；公开主页与普通内容能力已删除。

- [x] 个人终端可在本地启动，访客无需账户即可打开公开主页。
- [x] 公开主页具备可承载后续身份、内容和受限卡片的基础卡片结构，并提供明确的空状态。
- [x] 主题默认跟随系统，同时允许选择浅色或深色并记住所有者的选择。
- [x] 浅色主题以白色为主要背景，深色主题保持同等信息层级和可读性。
- [x] 一条浏览器级自动化测试通过真实应用入口和测试数据存储验证公开主页，而不是直接测试内部组件。
- [x] 测试环境可以替换时间、外部资产来源、价格、身份认证和安全存储，而生产运行不暴露这些测试替身。
- [x] 页面在桌面、中等宽度和手机宽度下均无横向溢出或不可访问内容。

## 评论

2026-07-26 实现完成（分支 `feat/public-homepage-foundation`）：

- 技术栈：Next.js 16 App Router + TypeScript + Playwright（锁定 1.61.1，新版触发本机 pnpm 供应链最少年限策略）。
- 公开主页 `src/app/page.tsx`：服务端渲染卡片网格 + 空状态；卡片数据来自 `CardStore` 端口（生产为 `data/cards.json` 文件存储）。
- 主题：`src/ui/theme-switcher.tsx` + 布局内联脚本（防闪烁），localStorage 记住浅色/深色/跟随系统。
- 组合根 `src/server/composition.ts`：装配时间、卡片、资产来源、价格、身份认证、安全存储六个端口；`APP_ENV=test` 时装配内存替身。
- 测试路由 `src/app/test-doubles/*`：仅测试环境可用，生产返回 404（注意：下划线开头的 App Router 目录不参与路由，故未用 `__test__` 命名）。
- 自动测试：`pnpm test`（构建 + 11 条浏览器级测试）全部通过；`pnpm typecheck` 通过。
- 人工验收待做：浅色/深色 × 桌面/中等/手机宽度的视觉检查（已自查截图，无横向溢出，浅色为白色主背景）。

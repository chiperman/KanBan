# 04 — 卡片编排与响应式布局

**What to build:** 让所有者通过独立编辑模式编排卡片，同时让同一份桌面排序自动适配不同屏幕。日常浏览保持稳定，避免误拖动或误改卡片宽度。

**Blocked by:** 03 — 公开内容编辑与访问级别

**Status:** ready-for-agent

- [ ] 正常浏览模式下不能拖动、排序或调整卡片宽度。
- [ ] 所有者可以进入和退出独立的布局编辑模式，访客不能进入该模式。
- [ ] 所有者可以拖拽卡片改变顺序，保存后刷新页面仍保留新顺序。
- [ ] 每张卡片可以设置占用一格、两格或三格宽度，卡片高度由内容决定。
- [ ] 桌面宽度显示三列逻辑网格，中等宽度自动收缩为两列，手机宽度自动变为单列。
- [ ] 窄屏按桌面排序自动重排，不需要维护第二套布局。
- [ ] 公开主页与所有者视图使用同一布局规则，受限卡片不会导致未登录页面明显跳动。
- [ ] 浏览器级测试在三种代表性视口验证顺序、宽度、重排和模式权限。

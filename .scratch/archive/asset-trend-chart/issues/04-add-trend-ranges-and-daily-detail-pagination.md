# 04 — 增加趋势区间与每日明细分页

**What to build:** 让所有者在不同时间跨度之间切换，并在折线图下方分页查看精确的每日金额，同时保证分页和图表区间互不干扰。

**Blocked by:** 03 — 展示总资产默认 30 日折线图

**Status:** resolved

**Adjusted by:** `.scratch/archive/personal-asset-dashboard-rebuild/issues/02-return-analysis-and-funding-records.md`

- [x] 趋势区间支持 `7日`、`30日`、`90日`、`1年` 和 `全部`。
- [x] 首次使用默认选择 `30日`，之后恢复所有者上一次选择。
- [x] 区间按连续上海自然日计算，而不是按已有观测条数计算。
- [x] `全部` 从首次每日趋势观测日期延伸至当前上海自然日。
- [x] 切换区间后折线、端点状态、实际覆盖日期、金额变化和变化比例同步更新。
- [x] 折线图下方展示每日明细，并在桌面端默认展开。
- [x] 每日明细按日期从新到旧排列，每页显示 30 条。
- [x] 每条正常明细只显示日期和当前计价货币金额；异常记录额外显示简短状态。
- [x] 明细分页不会改变折线图区间。
- [x] 切换趋势区间或计价货币后，每日明细回到第一页。
- [x] 隐藏关键信息时，每日明细金额及相关区间变化同时隐藏。
- [x] 区间控制和分页具有可访问名称、键盘操作、可见焦点和至少 40px 的交互命中区域。
- [x] 通过所有者首页浏览器测试接缝验证区间记忆、上海日历范围、全部区间、分页独立性、倒序、重置页码和隐藏状态。

## 答案

- 增加全局趋势区间选择与本地持久化；图表按连续上海自然日更新，全部区间从首个每日趋势观测延伸至当前日。
- 每日明细默认展开、倒序、每页 30 条，分页独立于图表范围；切换区间或计价货币回到第一页。
- 复用 Vibe 控件和焦点样式；隐私模式不渲染明细。
- 验收：`pnpm typecheck`、`pnpm build`、`pnpm exec playwright test e2e/daily-snapshots-asset-change.spec.ts`（12 passed）。

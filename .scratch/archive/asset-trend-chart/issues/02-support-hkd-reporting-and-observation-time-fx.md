# 02 — 完整支持 USD、CNY、HKD 历史计价

**What to build:** 让所有者能够以 USD、CNY 或 HKD 查看当前及历史资产，并确保每个历史金额使用当时的可靠汇率，不被今天的汇率重写。

**Blocked by:** 01 — 分离日初基准与每日趋势观测

**Status:** resolved

- [ ] 计价货币完整支持 USD、CNY 和 HKD，默认仍为 USD。
- [ ] 当前总资产、每日趋势观测和来源趋势观测均保存或提供三种计价货币金额。
- [ ] 所有者切换到 HKD 后，当前总资产和已有历史明细使用 HKD 展示。
- [ ] 页面同时展示可用的 `USD/CNY` 与 `USD/HKD` 汇率观察。
- [ ] 提供方返回 `CNY/USD` 或 `HKD/USD` 时只在展示方向上取倒数，不改变底层换算语义。
- [ ] 历史金额使用该次趋势观测对应的可靠汇率；之后汇率变化不会重算旧观测。
- [ ] 某次观测缺少可靠 HKD 汇率时，HKD 金额保持不可用并标记不完整，不使用固定汇率、当前汇率或零值。
- [ ] USD 和 CNY 的现有估值、精度、直接或反向汇率处理保持不变。
- [ ] 未认证响应不包含三种货币的历史资产金额或汇率观测。
- [ ] 通过所有者首页浏览器测试接缝验证三种货币切换、历史汇率固定、反向货币对、缺失汇率和持久化重载。

## 答案

- 已支持 USD、CNY、HKD；总资产、每日趋势观测与来源趋势观测共用计价货币。
- 每日观测持久化三币种金额及原始汇率观察，SQLite schema 升级至 v7；历史金额不使用当前汇率重算。
- 页面同时展示 `USD/CNY`、`USD/HKD`，反向货币对仅在展示时取倒数；缺少可靠 HKD 汇率时金额为不可用并标记不完整。
- 验收：`pnpm typecheck`；43 条聚焦 Playwright 用例通过。

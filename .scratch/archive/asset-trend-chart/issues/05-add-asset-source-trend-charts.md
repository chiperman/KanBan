# 05 — 增加资产来源趋势图

**What to build:** 让所有者在每个现有资产来源卡片中查看该来源总额的历史走势，并与总资产图使用相同的区间和计价货币进行比较。

**Blocked by:** 04 — 增加趋势区间与每日明细分页

**Status:** resolved

- [x] 每个具有历史观测的资产来源在现有来源卡片内展示来源总额折线图。
- [x] 来源图复用总资产图的直线缺口连接、自动纵轴、点详情和异常状态规则。
- [x] 所有来源图统一跟随总资产区域选择的趋势区间。
- [x] 所有来源图统一跟随当前 USD、CNY 或 HKD 计价货币。
- [x] 来源缺少某日观测时只在该来源图中保留空值并连接相邻真实观测，不影响其他来源或总资产图，也不生成该日金额。
- [x] 不完整或过期来源观测显示已知金额和必要状态，但不补零。
- [x] 新来源从首次成功同步日期开始形成自身趋势，不改写更早的总资产历史。
- [x] 已断开的来源继续保留既有来源趋势；永久删除后按现有生命周期规则移除对应历史。
- [x] 单项持仓不产生独立折线图或历史入口。
- [x] 隐藏关键信息时，每个来源的金额、坐标、点详情和曲线形状同时隐藏。
- [x] 一格、两格和三格宽度的来源卡片均保持现有内容层级和可读布局。
- [x] 通过所有者首页浏览器测试接缝验证多来源同步、独立缺失日及连续折线、统一区间、统一货币、新增来源、断开来源及隐藏状态。

## 答案

- 来源卡片中的 SVG 仅绘制来源账户总额；每个来源独立按共享趋势区间保留缺失空值、连接相邻真实观测并计算纵轴。
- 总览将趋势区间状态提升为全局偏好，来源图与 USD/CNY/HKD 切换保持同步。
- 敏感模式不渲染来源曲线或数据点；断开来源的既有记录继续可读。
- 验收：`pnpm build`、`pnpm typecheck`、`pnpm exec playwright test e2e/daily-snapshots-asset-change.spec.ts`（13 passed）。

# 01 — 证券持仓表展示交易时段行情

**What to build:** 所有者在证券持仓明细的既有“现价 / 成本”区域看到当前报价所属的可验证交易时段与行情时间；Longbridge 的盘前、常规盘、盘后、夜盘和未知证据被如实区分，加密资产保留 24 小时语义，且已确认的正式日结绝不受当前盘外行情影响。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] Longbridge 当前报价只根据官方返回的会话、价格与时间证据分类；不通过本机时间、市场日历或标的代码猜测时段，未知证据明确降级。
- [x] 在不改动卡片布局、表头、成本价展示和盈亏口径的前提下，证券表显示时段与行情时间；加密资产显示 24h，非证券和期权保持真实不可用/未知状态。
- [x] 行情权限、延迟、单标的无报价、市场休市、部分响应和刷新失败都有可见且不伪造的降级；凭证和权限边界保持只读。
- [x] 当前快照、日初基准、每日趋势观测与正式日结的写入和语义保持隔离；盘前、盘后和夜盘报价不能覆盖官方日 K 常规盘日结。
- [x] 适配器与生产形态浏览器测试覆盖各会话、未知、24h、旧快照、延迟与过期情形，并证明正式日结不受影响。

## 答案

- 原生 Longbridge Keychain 边界输出主报价、盘前、盘后、夜盘候选、原始交易状态与可判定的延迟信息；夜盘显式启用。适配器只比较供应商时间戳，冲突、未知状态、无效时间和无报价均降级为未知，不读取本机时钟、市场日历或代码后缀。
- 持仓增加 `quoteEvidence`。证券在既有“现价 / 成本”区域显示时段与上海行情时间；加密资产显示 `24h`；旧快照没有独立报价时间证据时显示“时间不可用”。敏感信息隐藏时不显示此元信息。
- 当前报价读取与正式日结日 K 读取保持独立入口；期权不进入新增报价读取；完整刷新单标的缺报价时保留上次报价证据并标为保留。
- 已通过 `pnpm typecheck`、`pnpm build`、`pnpm native:longbridge:build`。相关三份 E2E 共 25 条中 23 条通过；两条无关失败是既有 CNY 折算断言和锁定页对构建产物字符串的扫描。全量 `pnpm test` 为 234 通过、28 条失败，失败集中在工作区已有的币种折算、趋势/总览、锁定页、布局与其他来源改动。

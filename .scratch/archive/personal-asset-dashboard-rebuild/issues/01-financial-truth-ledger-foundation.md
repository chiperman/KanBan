# 01 — 资金账本、长桥参考汇率与收益派生基础

**What to build:** 增加仅记录初始投入、外部入金和外部出金的投资资金进出账本，并形成可复算的累计净投入、组合投资盈亏、区间投资盈亏与比例领域服务。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] SQLite 以增量、事务化、可回退的 schema 迁移保存账本、原始币种、备注、发生时间、三币种可用值与长桥参考汇率来源/时间；不改写任何既有资产记录。
- [x] 只有一个可选初始投入；外部入金/出金允许同日多笔与任意历史补录。
- [x] 账本 API 继续受所有者授权，校验金额、币种、日期与备注，不读取或保存来源凭证。
- [x] 累计净投入、组合投资盈亏、区间资产变化、区间投资盈亏与资金发生日加权比例使用 decimal 计算；不可靠端点/汇率/分母显示数据不足。
- [x] USD 为默认；CNY、HKD 统一仅使用长桥参考汇率观察。没有可靠观察时不可折算，不能退回其他来源或固定值。
- [x] 单元、SQLite 迁移、所有者 API、备份兼容与未认证隔离均有测试。

## 验收口径

- 来源账户/平台总额是当前组合价值真相；账本不改变来源总额或趋势观测。
- `组合投资盈亏 = 当前完整总资产 - 累计净投入`。
- `区间投资盈亏 = 区间资产变化 - 区间内净外部投入`。

## 答案

- SQLite schema v13 增量增加 `investment_cashflows`；历史账本补录不会写入、重建或覆盖任何资产快照、趋势观测或日结。
- 账本仅允许唯一且最早的初始投入；入金、出金以资金发生时点保存原币种金额与当时可用的长桥 USD/CNY、USD/HKD 观察。
- 备份格式升级为 v3，恢复时继续删除凭证引用并断开来源；v1/v2 自动以空账本兼容。账本换算证据会在恢复预演中复算校验，不能以篡改后的金额制造虚假收益。
- 自动化证据：`pnpm typecheck`、`pnpm build`、3 项账本领域/服务单测、8 项备份恢复浏览器测试、5 项账本 API 与 SQLite 迁移浏览器测试均通过。
- 未触碰真实来源、真实凭证或账户；本 Ticket 没有日常查看 UI，桌面/390px 收益分析页面归 R02 验收。

## 验收 seam

- 无凭证备份恢复公开测试替身：验证业务数据、资产卡片布局元数据与账本证据都可恢复，而凭证仍被剥离、来源仍为断开状态。
- 已认证工作台路由：验证总览、资产与持仓、收益分析、资产来源、数据健康和设置与安全的标题、导航、焦点、主题与无横向溢出。
- 锁定态直接路由：验证根路径、旧演示参数和所有受保护深链均不序列化或渲染资产、来源、趋势、账本或迁移测试数据。

## 评论

- R08 产品决定：日常总览使用按当前资产判断排序的来源摘要，以避免把低频布局管理重新堆回首页。第一代资产卡片的排序、隐藏、宽度与强制换行继续作为迁移元数据持久化、备份、恢复与校验；来源目录仍明确显示已隐藏状态。验收以 SQLite/备份恢复和来源目录可读性为准，不对新总览断言已退役卡片拼贴的 CSS 类。

## 答案

- 修改范围：完成 R08 的迁移保真、锁定隔离与全页响应式验收；来源目录保留已隐藏状态，备份恢复校验资产卡片的隐藏、跨度与强制换行元数据。
- 业务口径：来源账户/平台总额仍是组合总额真相；同步失败只保留上次真实数值与观测时间，后续不完整刷新不会降级同日完整趋势观测；断开来源会清除只读凭证而保留来源身份和历史数据。
- 自动化证据：`pnpm typecheck`、`pnpm test:unit`（17/17）、`pnpm build`、36 项定向 Playwright 均通过，覆盖 SQLite v2/v4/v6/v8/v12 增量迁移、重启、账本、备份、旧演示参数、深链隔离、断开与永久删除。
- 浏览器验收：隔离测试服务已覆盖桌面 1280px、中屏 800px、390px 手机、浅色/深色和减少动态效果；总览、资产与持仓、收益分析、资产来源、数据健康、设置与安全均可导航、无横向溢出、无相关控制台错误。
- 真实来源未覆盖项：本 Ticket 未调用真实账户、真实凭证、真实网络来源或硬件 Passkey；既有人工只读验收不被替身测试替代。
- 迁移影响和风险：不改写已有来源、快照、布局或账本数据，新增修复只约束未来趋势合并和断开时的凭证清除；没有新增 schema。未推送。

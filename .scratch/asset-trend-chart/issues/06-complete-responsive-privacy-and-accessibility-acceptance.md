# 06 — 完成移动端、隐私与可访问性交付

**What to build:** 让完整趋势功能在桌面、中等宽度和移动端都保持可理解、可操作和不泄露，并完成可交付的视觉与行为验收。

**Blocked by:** 05 — 增加资产来源趋势图

**Status:** ready-for-agent

- [ ] 移动端保留现有“查看分布与趋势”折叠入口，不新增第二套导航。
- [ ] 移动端打开该入口后，总资产图和每日明细均直接展开，不要求二次展开。
- [ ] 来源趋势在移动端来源卡片中保持可读，不造成横向页面溢出。
- [ ] 桌面、中等宽度和移动端使用相同的数据口径、趋势区间和计价货币。
- [ ] 隐藏关键信息后，页面无法通过金额、纵轴、点详情、折线路径或装饰图形推断资产变化。
- [ ] 未认证 HTML、序列化状态、接口和网络响应中不包含总资产或来源历史数据。
- [ ] 趋势区间、分页和可交互数据点均支持键盘访问、可见焦点和可理解的可访问名称。
- [ ] 减少动态效果设置会禁用非必要动画，但不移除状态表达。
- [ ] 明暗主题下的折线、断点、异常状态、提示框和焦点均保持足够辨识度。
- [ ] 视觉实现复用现有运行时 Token、共享组件和首页组合，不建立第二套视觉语言。
- [ ] 现有总资产、今日资产变动、资产分布、来源持仓、刷新和卡片布局行为无回归。
- [ ] 自动化浏览器验收覆盖完整用户路径，并单独记录桌面、中等宽度、移动端、明暗主题和减少动态效果的人工视觉检查结果。

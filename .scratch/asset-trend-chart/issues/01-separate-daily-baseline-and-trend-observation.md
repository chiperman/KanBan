# 01 — 分离日初基准与每日趋势观测

**What to build:** 让所有者在继续获得稳定“今日资产变动”基准的同时，看到会随当天后续成功刷新更新的趋势观测；既有历史无需清空，失败和缺失日期不会被伪造成零值或连续数据。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 每个上海自然日首次成功刷新同时建立不可改写的日初基准和初始每日趋势观测。
- [ ] 同一上海自然日内后续成功的价格或持仓刷新只更新每日趋势观测，不修改日初基准。
- [ ] “今日资产变动”始终使用日初基准计算，并保持现有非收益语义。
- [ ] 当天已有成功观测后刷新失败时，保留最后成功观测并标记过期或不完整，不写入零值。
- [ ] 当天没有任何成功刷新时不创建趋势点，也不把前一天金额复制到当天。
- [ ] 总资产和各资产来源的完整、不完整、过期状态随趋势观测持久化。
- [ ] 既有首次每日快照升级后可同时作为该日基准和初始趋势观测，不要求清空或自动回填历史。
- [ ] 同一天重复写入、进程重启和页面重载不会产生重复日期记录。
- [ ] 断开来源后继续保留既有历史；永久删除来源历史仍遵循现有二次确认规则。
- [ ] 业务数据备份与恢复能够完整往返日初基准和每日趋势观测。
- [ ] 通过既有所有者首页浏览器测试接缝验证上海日界线、同日更新、跨日缺口、失败恢复、旧数据兼容和持久化。

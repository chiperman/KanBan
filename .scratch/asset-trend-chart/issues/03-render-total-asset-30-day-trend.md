# 03 — 展示总资产默认 30 日折线图

**What to build:** 让所有者进入首页后直接看到最近 30 个上海自然日的总资产变化方向、可信状态和区间资产变动，而不需要逐行阅读历史记录。

**Blocked by:** 01 — 分离日初基准与每日趋势观测；02 — 完整支持 USD、CNY、HKD 历史计价

**Status:** resolved

**Adjusted by:** `.scratch/personal-asset-dashboard-rebuild/issues/04-overview-confidence-and-today-judgment.md`

- [x] 首页现有“总资产趋势”区域展示最近 30 个上海自然日的总资产折线图，不新增卡片或页面。
- [x] 折线使用直线连接，不平滑，不使用面积填充。
- [x] 纵轴按当前可见有效金额自动缩放，不强制从零开始。
- [x] 缺少趋势观测的日期形成断线，不补零、不跨缺口连线。
- [x] 完整、不完整和过期观测具有明确且一致的状态区分。
- [x] 正常数据点详情仅显示日期和当前计价货币金额，不显示具体时刻。
- [x] 异常数据点只额外增加一条简短状态说明。
- [x] 区间资产变动使用当前 30 日内最早和最晚的完整观测，展示实际覆盖日期、金额变化和变化比例。
- [x] 少于两个完整观测时显示“数据不足”，不计算区间变化。
- [x] 文案只使用“区间资产变动”和“资产变化比例”，不称为收益、盈亏或收益率。
- [x] 无历史时显示首次成功同步提示；只有一个有效观测时可以显示单点，但区间变化仍为数据不足。
- [x] 隐藏关键信息时不展示金额、金额坐标、点详情或可推断变化的曲线形状。
- [x] 通过所有者首页浏览器测试接缝验证折线、断点、状态、详情、区间计算、空状态、单点状态和隐藏状态。

## 答案

- 在既有总资产趋势区域加入 30 个连续上海自然日的直线 SVG；缺少观测断线，纵轴仅按可见金额缩放。
- 点详情只含日期、金额和异常简短状态；区间资产变动仅使用范围内首尾完整观测，少于两点显示“数据不足”。
- 隐私模式移除图形、金额坐标和点详情。
- 验收：`pnpm typecheck`、`pnpm build`、`pnpm exec playwright test e2e/daily-snapshots-asset-change.spec.ts`（11 passed）。

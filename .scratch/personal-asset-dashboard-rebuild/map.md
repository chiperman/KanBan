# KanBan 个人资产看板全面产品重构

## Notes

- 本重构以本地优先、单所有者、私有、只读和数据真实性为不可突破边界。
- 当前工作区已有“工作台迁移验收、趋势观测与汇率”的未提交改动；它们不属于本重构的自动吸收范围，后续仅在显式兼容与回归下共存。
- 资金账本只记录资金跨越投资组合边界的事实；它不记录平台间转账、交易、换汇、申赎或仓位调整。

## Decisions-so-far

- 总资产以已连接来源返回的账户/来源总额为组合汇总真相；持仓明细是观察层，价格、覆盖与平台盈亏可以不完整，不能仅因与总额不一致而标记总额错误。
- USD 为默认计价货币；CNY、HKD 的当前与历史换算统一依赖可用的长桥参考汇率观察，并保留来源与观测时间。没有可靠长桥参考汇率时，如实显示无法折算。
- 初始投入、外部入金和外部出金形成独立账本。组合投资盈亏由资产总额和累计净投入派生，不把资产变化直接称为收益。
- 区间投资盈亏只在区间首尾存在完整资产观测、并且区间资金账本可可靠折算时计算；历史补录会重算派生结果，但不会补造资产观测或趋势曲线。
- 一级导航收口为总览、资产与持仓、收益分析、资产来源、设置与安全；数据健康保留为资产来源下可发现的诊断入口，不与日常查看争夺首页。
- R01 已完成：schema v13 增量保存资金账本与长桥汇率证据，备份 v3 保留账本但继续剥离凭证；对应验收见 `issues/01-financial-truth-ledger-foundation.md`。

## Fog

- 真实长桥参考汇率不可用时，CNY/HKD 是否只显示 USD 原值，还是允许所有者明确导入可审计的离线参考率；本期先不增加第二来源或手工汇率入口。
- 证券指数同资金流比较需要单独确认数据提供方、许可和总回报口径；本重构保留明确的未配置状态，不接入临时网页数据。

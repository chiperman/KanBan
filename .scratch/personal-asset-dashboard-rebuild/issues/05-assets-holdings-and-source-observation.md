# 05 — 资产与持仓及来源观察层

**What to build:** 新增跨来源的资产与持仓页面，并收敛来源详情中的观察性信息，让账户总额真相与持仓明细覆盖清楚分层。

**Blocked by:** 03 — 五目的地应用壳与可靠返回路径.

**Status:** ready-for-agent

- [ ] `资产与持仓` 按来源/资产类别/估值状态筛选并比较持仓；每项展示数量、现价、来源币种、市值、价格变动、价格来源和可用平台盈亏。
- [ ] 不可可靠获得成本、平台盈亏或区间变化时显示明确降级，不显示推测值或零。
- [ ] 每个来源独立显示账户/平台总额、持仓明细覆盖、仅汇总产品和未估值资产；持仓合计不取代账户总额。
- [ ] 来源详情保留接入、重新授权、手工资产、单来源刷新和生命周期，但将危险操作与阅读层清晰隔离。
- [ ] 浏览器覆盖来源总额与明细不一致、仅汇总、未估值、过期、来源筛选、键盘和移动端。

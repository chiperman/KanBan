# 05 — 资产与持仓及来源观察层

**What to build:** 新增跨来源的资产与持仓页面，并收敛来源详情中的观察性信息，让账户总额真相与持仓明细覆盖清楚分层。

**Blocked by:** 03 — 五目的地应用壳与可靠返回路径.

**Status:** resolved

- [x] `资产与持仓` 按来源/资产类别/估值状态筛选并比较持仓；每项展示数量、现价、来源币种、市值、价格变动、价格来源和可用平台盈亏。
- [x] 不可可靠获得成本、平台盈亏或区间变化时显示明确降级，不显示推测值或零。
- [x] 每个来源独立显示账户/平台总额、持仓明细覆盖、仅汇总产品和未估值资产；持仓合计不取代账户总额。
- [x] 来源详情保留接入、重新授权、手工资产、单来源刷新和生命周期，但将危险操作与阅读层清晰隔离。
- [x] 持仓范围变化仅在来源提供可信价格历史或完整端点时显示；其他情况下保留当前观察并说明不能形成区间结论。
- [x] 浏览器覆盖来源总额与明细不一致、仅汇总、未估值、过期、来源筛选、键盘、桌面与 390px；确认筛选不会把来源总额误称为持仓合计。

## 评论

- 修改范围：新增 `/assets` 跨来源资产与持仓工作区；来源总额、明细覆盖、仅汇总产品和未估值状态分层展示；来源详情保留单来源阅读与生命周期入口。
- 业务口径：账户/平台总额是组合汇总真相；持仓明细仅为观察，平台盈亏仅显示来源明确提供的原生口径；CNY/HKD 仅以长桥 USD 参考汇率展示。
- 自动化证据：`pnpm typecheck`、`pnpm test:unit`（17/17）及总览—持仓—来源详情 Playwright（12/12）通过。
- 浏览器验收：隔离测试服务覆盖桌面与 390px、键盘筛选、来源总额/明细不一致、过期、未估值、仅汇总和来源详情返回路径；无横向页面溢出。
- 真实来源未覆盖项：本 Ticket 未使用真实账户或凭证；只以隔离的只读来源替身验收。
- 迁移影响和风险：不新增或改写业务数据；严格汇率显示会在缺少长桥观察时诚实显示“无法折算”。

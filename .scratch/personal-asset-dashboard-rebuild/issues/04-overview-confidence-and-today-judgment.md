# 04 — 总览可信度与今日资产判断

**What to build:** 重做总览为日常判断页，清晰呈现当前总资产、可信度、资金/盈亏摘要、短趋势、来源摘要和少量快捷操作。

**Blocked by:** 01 — 资金账本、长桥参考汇率与收益派生基础; 03 — 五目的地应用壳与可靠返回路径.

**Status:** ready-for-agent

- [ ] 总资产主卡分层显示：金额、计价货币、估值完整性、过期来源、未估值资产、长桥参考汇率与更新时间。
- [ ] 总览明确区分“今日资产变化”“累计净投入”“组合投资盈亏”，不把资产变化称为收益。
- [ ] 短趋势保留真实可用范围、断点、不完整/过期说明；深度历史与账本编辑移到收益分析。
- [ ] 来源摘要只显示来源总额、同步/估值可信度与进入详情的入口；不再承载完整持仓、凭证或危险操作。
- [ ] 全局刷新、金额隐藏、币种切换和进入资金记录是仅有的日常快捷操作。
- [ ] 浏览器覆盖完整、过期、未估值、仅汇总、无长桥汇率、空账本、隐私及 390px。

# 04 — 总览可信度与今日资产判断

**What to build:** 重做总览为日常判断页，清晰呈现当前总资产、可信度、资金/盈亏摘要、短趋势、来源摘要和少量快捷操作。

**Blocked by:** 01 — 资金账本、长桥参考汇率与收益派生基础; 03 — 五目的地应用壳与可靠返回路径.

**Status:** resolved

- [x] 总资产主卡分层显示：金额、计价货币、估值完整性、过期来源、未估值资产、长桥参考汇率与更新时间。
- [x] 总览明确区分“今日资产变化”“累计净投入”“组合投资盈亏”，不把资产变化称为收益。
- [x] 短趋势保留真实可用范围、断点、不完整/过期说明；深度历史与账本编辑移到收益分析。
- [x] 来源摘要只显示来源总额、同步/估值可信度与进入详情的入口；不再承载完整持仓、凭证或危险操作。
- [x] 全局刷新、金额隐藏、币种切换和进入资金记录是仅有的日常快捷操作。
- [x] 浏览器覆盖完整、过期、未估值、仅汇总、无长桥汇率、空账本、隐私及 390px。

## 完成记录（2026-08-09）

- 认证后的 `/` 升级为“今日判断”总览：来源账户/平台总额为主视觉；当 CNY/HKD 缺少长桥参考汇率时明确显示无法折算，不回退到其他来源或固定汇率。
- 总览分开显示今日资产变化、累计净投入与组合投资盈亏；今日变化明确包含可能的外部资金，账本没有初始投入事实时，本金与组合盈亏均降级为数据不足，绝不将其当作零本金。
- 短趋势只展示真实每日观察与断点；非 USD 历史缺少可追溯长桥汇率时不补造曲线。来源摘要只表达来源总额、同步/估值状态、仅汇总产品和详情入口，不把持仓明细差异作为总额异常。
- 全局刷新改为显式操作，不在打开总览时静默刷新并改变已读数；金额隐藏同时遮蔽本金额、盈亏、趋势及来源身份/状态。
- 自动化证据：`pnpm typecheck`、`pnpm build`、投资收益领域测试（3/3）以及总览、应用壳、收益分析 Playwright 回归（5/5）通过。
- 浏览器验收：隔离测试服务的桌面与 390px 总览覆盖币种切换、隐私、资金入口、趋势断点、无初始投入、过期/未估值、仅汇总和无长桥汇率；无横向溢出。真实来源、真实账户、真实凭证和硬件 Passkey 均未使用。
- 迁移影响：无新迁移，不改写来源、快照、卡片布局、凭证或账本历史；仅修正账本缺少初始投入时的收益派生降级。

## 复核修正（2026-08-09）

- 复核发现：仅有手工资产记录时，旧实现会把相邻记录延展到未观测上海自然日，违反“不补造历史曲线”口径。
- 本次回归测试边界：总览的趋势渲染、非 USD 报告换算与未观测日期提示；验证只通过认证页面可见行为，不读取实现内部状态。

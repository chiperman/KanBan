# 02 — 收益分析与资金记录页面

**What to build:** 交付收益分析页面，提供资金补录、编辑、删除、历史记录与收益解释，而首页只保留入口和摘要。

**Blocked by:** 01 — 资金账本、长桥参考汇率与收益派生基础.

**Status:** ready-for-agent

- [ ] `收益分析` 可新增初始投入、外部入金、外部出金，按发生时间排序，显示原始币种、备注、可用换算与汇率证据。
- [ ] 编辑或删除会立即重算派生结果，不改写资产快照；危险删除有清晰确认与失败恢复。
- [ ] 显示当前总资产、累计净投入、组合投资盈亏、选定区间资产变化、区间投资盈亏、比例、实际覆盖日期和数据不足原因。
- [ ] 范围至少有近几日、周、月、季度、年、全部和自定义起止日期；缺失资产观测保持断点，不能补值。
- [ ] 隐藏关键信息时同时隐藏资金、备注、收益数值和可推断曲线。
- [ ] 浏览器覆盖历史补录、同日多笔、部分取回、无完整端点、缺失汇率、编辑、删除、键盘与 390px。

## 非目标

- XIRR、指数对比、交易流水、税务、银行接口或平台充值/提现导入。

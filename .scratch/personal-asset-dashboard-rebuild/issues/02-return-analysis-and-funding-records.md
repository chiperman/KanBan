# 02 — 收益分析与资金记录页面

**What to build:** 交付收益分析页面，提供资金补录、编辑、删除、历史记录与收益解释，而首页只保留入口和摘要。

**Blocked by:** 01 — 资金账本、长桥参考汇率与收益派生基础.

**Status:** resolved

- [x] `收益分析` 可新增初始投入、外部入金、外部出金，按发生时间排序，显示原始币种、备注、可用换算与汇率证据。
- [x] 编辑或删除会立即重算派生结果，不改写资产快照；危险删除有清晰确认与失败恢复。
- [x] 显示当前总资产、累计净投入、组合投资盈亏、选定区间资产变化、区间投资盈亏、比例、实际覆盖日期和数据不足原因。
- [x] 范围至少有近几日、周、月、季度、年、全部和自定义起止日期；缺失资产观测保持断点，不能补值。
- [x] 隐藏关键信息时同时隐藏资金、备注、收益数值和可推断曲线。
- [x] 浏览器覆盖历史补录、同日多笔、部分取回、无完整端点、缺失汇率、编辑、删除、键盘与 390px。

## 完成记录（2026-08-09）

- `/performance` 由占位页升级为收益分析工作区：当前总资产、累计净投入、组合投资盈亏与区间解释分层呈现；来源账户/平台总额保持组合汇总真相，不以持仓明细强制对账。
- 当前 USD 总额由现有来源估值服务汇总；CNY/HKD 只在存在长桥 USD/CNY、USD/HKD 参考观察时由 USD 折算，缺失时如实显示数据不足。
- 资金账本支持新增、编辑、确认永久删除和历史补录；修改只更新派生结果，不改写趋势观测、来源快照或收益曲线。初始投入唯一性、原币种、备注和历史汇率证据继续由 R01 服务端接口校验。
- 走势范围覆盖近 3/7/30 日、季度、年、全部与自定义日期；缺失、不完整或过期观测保留断点，区间结论标出实际完整端点与无法计算的原因。收益比例使用既有精确十进制 Modified Dietz 结果，不转为 JavaScript `Number`。
- 隐藏关键信息会同时遮蔽本金、收益、备注、换算证据和趋势值；移动端快捷命令与底部导航留出至少 8px 操作间距。
- 自动化证据：`pnpm typecheck`、`pnpm build`、`pnpm test:unit`（11/11）、`pnpm exec playwright test e2e/investment-cashflows.spec.ts`（1/1）与 `pnpm exec playwright test e2e/rebuild-return-analysis.spec.ts`（1/1）通过。
- 浏览器验收：隔离测试服务的已认证生产构建在桌面与 390px、浅色与深色可渲染，无相关控制台错误、无横向溢出；覆盖金额隐藏与移动导航安全间距。未使用真实来源、真实凭证或真实账户。
- 迁移影响：无新增迁移，本 Ticket 仅消费 R01 的增量账本表与接口；现有来源、快照、布局和凭证均不被修改。真实长桥汇率、真实来源完整性和硬件 Passkey 不在本 Ticket 自动化覆盖内。

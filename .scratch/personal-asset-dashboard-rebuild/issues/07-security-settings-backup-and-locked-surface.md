# 07 — 设置安全、备份与锁定面收口

**What to build:** 将新账本纳入安全设置与无凭证备份恢复，并移除锁定状态下进入虚构资产演示的产品入口。

**Blocked by:** 01 — 资金账本、长桥参考汇率与收益派生基础; 03 — 五目的地应用壳与可靠返回路径.

**Status:** ready-for-agent

- [ ] 设置与安全显示账本备份范围与恢复影响，但不显示来源凭证、汇率密钥或真实资产数据。
- [ ] 备份/预演/恢复包含账本和汇率观察，继续清除来源凭证并以断开状态恢复来源。
- [ ] 锁定页只包含实际所有者预置或登录入口、主题与非敏感时间；不提供演示模式、资产形状或任何可推断投资数据。
- [ ] Passkey/TOTP、会话锁定、退出、超时、断开、永久删除和敏感信息隐藏无回归。
- [ ] 浏览器和数据恢复测试验证未认证隔离、备份敏感字段扫描、迁移后回退可读性与 390px。

# 01 — 资金账本、长桥参考汇率与收益派生基础

**What to build:** 增加仅记录初始投入、外部入金和外部出金的投资资金进出账本，并形成可复算的累计净投入、组合投资盈亏、区间投资盈亏与比例领域服务。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] SQLite 以增量、事务化、可回退的 schema 迁移保存账本、原始币种、备注、发生时间、三币种可用值与长桥参考汇率来源/时间；不改写任何既有资产记录。
- [ ] 只有一个可选初始投入；外部入金/出金允许同日多笔与任意历史补录。
- [ ] 账本 API 继续受所有者授权，校验金额、币种、日期与备注，不读取或保存来源凭证。
- [ ] 累计净投入、组合投资盈亏、区间资产变化、区间投资盈亏与资金发生日加权比例使用 decimal 计算；不可靠端点/汇率/分母显示数据不足。
- [ ] USD 为默认；CNY、HKD 统一仅使用长桥参考汇率观察。没有可靠观察时不可折算，不能退回其他来源或固定值。
- [ ] 单元、SQLite 迁移、所有者 API、备份兼容与未认证隔离均有测试。

## 验收口径

- 来源账户/平台总额是当前组合价值真相；账本不改变来源总额或趋势观测。
- `组合投资盈亏 = 当前完整总资产 - 累计净投入`。
- `区间投资盈亏 = 区间资产变化 - 区间内净外部投入`。

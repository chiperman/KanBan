# 08 — 全产品迁移、浏览器验收与发布准备

**What to build:** 证明全面重构后已有业务数据、来源和安全边界保持可用，并完成核心页面的自动化与人工浏览器验收。

**Blocked by:** 02 — 收益分析与资金记录页面; 04 — 总览可信度与今日资产判断; 05 — 资产与持仓及来源观察层; 06 — 资产来源健康、失败恢复与低噪声提示; 07 — 设置安全、备份与锁定面收口.

**Status:** ready-for-agent

- [ ] 已有来源、来源身份、资产卡片、布局、手工记录、日初基准、趋势观测、正式日结和凭证引用在迁移后保持可读，无需重新授权。
- [ ] SQLite 完整性、迁移重启、备份恢复、账本补录重算和旧版本应用回退均有可复验自动化证据。
- [ ] 锁定、总览、资产与持仓、收益分析、资金记录、来源、数据健康、设置与安全在桌面、中屏、390px、浅色/深色与减少动态效果下有浏览器验收。
- [ ] 类型检查、单元、集成、相关生产构建和针对性浏览器套件全部通过；与本重构无关的既有失败独立报告。
- [ ] 真实来源、真实账户、真实凭证和硬件 Passkey只记录所有者明确授权后的人工验收，不将替身列为真实覆盖。

# 05 — 数据健康诊断页

**What to build:** 提供只读的数据健康入口，让所有者按时间范围、来源和数据完整性诊断同步、估值与历史覆盖，并能进入相关来源详情处理已有的手动操作。

**Blocked by:** 03 — 资产来源列表、详情与生命周期.

**Status:** ready-for-agent

- [ ] 数据健康显示来源同步状态、最后成功时间、过期数据、估值完整性和人可理解的失败原因。
- [ ] 所有者可按时间范围、来源和完整性查看既有历史观测与数据缺口，而总览仍只呈现简洁总资产趋势。
- [ ] 数据健康可进入相应来源详情，但不提供全局刷新、单来源刷新、自动修复、调度或通知能力。
- [ ] 诊断页面不将未估值、过期或不完整数据伪装为零资产或完整历史。

# 07 — 工作台数据保真迁移与跨页面验收

**What to build:** 对已完成的资产管理工作台进行跨页面验收，证明本次重组没有改变现有资产来源、快照、布局、凭证引用、只读权限或来源生命周期，也不要求所有者重新授权。

**Blocked by:** 02 — 总览收口与布局管理模式; 04 — 独立来源接入与重新授权流程; 05 — 数据健康诊断页; 06 — 设置与安全收口.

**Status:** ready-for-agent

- [ ] 既有自动来源、观察钱包和手工资产记录在重组后仍可从对应工作台入口访问，无需重新接入或重新授权。
- [ ] 既有来源身份、持仓、快照、趋势、手工日期记录、卡片布局和凭证引用保持原有业务语义。
- [ ] 既有只读权限检查、断开、永久删除、估值真实性、刷新和备份凭证隔离回归仍通过。
- [ ] 锁定状态和每个已认证入口均通过浏览器测试验证，不泄露资产、来源、地址、快照或凭证。
- [ ] 在桌面、中等宽度和手机宽度完成总览、来源、数据健康、设置与安全的视觉与可访问性回归。
- [ ] 真实来源与硬件 Passkey 验收继续只在所有者确认的最小只读授权条件下单独进行，不将测试替身当作真实验收。

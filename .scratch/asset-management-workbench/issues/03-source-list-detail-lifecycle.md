# 03 — 资产来源列表、详情与生命周期

**What to build:** 提供统一的资产来源管理页面和来源详情，使自动账户、观察钱包和手工资产记录可在同一入口发现、查看和管理；将单来源刷新、手工记录编辑和生命周期危险操作从总览迁移到详情。

**Blocked by:** 01 — 工作台应用壳与主导航.

**Status:** ready-for-agent

- [ ] 资产来源页在同一列表中展示自动账户、观察钱包和手工资产记录，并能明确识别来源类型和生命周期状态。
- [ ] 来源摘要、列表项均可进入受所有者会话保护的来源详情。
- [ ] 自动来源详情展示来源身份、持仓、状态、最后更新时间和单来源刷新；手工资产记录展示其日期记录与允许的编辑操作。
- [ ] 来源详情只显示授权状态、校验时间和权限摘要，绝不回显 API Secret、OAuth Token、TOTP 或其他凭证原文。
- [ ] 隐藏、断开和永久删除的业务含义保持既有区别；断开和永久删除仅出现在详情的独立危险操作区，保留既有确认保护。
- [ ] 手工资产记录继续是无凭证来源，不伪造持仓、同步或断开行为。
- [ ] 总览卡片不再承担完整持仓或生命周期操作，已有来源、来源身份与快照仍可正常访问。
- [ ] 使用 Playwright 覆盖来源列表、详情跳转、单来源刷新、手工记录和生命周期行为。

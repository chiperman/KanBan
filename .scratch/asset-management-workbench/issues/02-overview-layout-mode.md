# 02 — 总览收口与布局管理模式

**What to build:** 使总览回归日常资产查看，并提供明确进入和退出的布局管理模式。总览保留总资产、资产变化、分布、简洁趋势、来源摘要、显示币种、金额隐藏、全局刷新和锁定；来源管理、凭证配置与危险操作不再常驻其中。

**Blocked by:** 01 — 工作台应用壳与主导航.

**Status:** resolved

- [x] 已认证所有者进入总览时，只看到阅读信息和已确认的快捷查看控制，不看到来源接入表单、凭证配置或断开/永久删除操作。
- [x] 所有者可明确进入和退出布局管理模式；非编辑状态下卡片不表现为可拖拽管理界面。
- [x] 布局管理模式中排序、宽度、强制换行和隐藏卡片每次操作立即保存；刷新或重新打开后保持结果。
- [x] 来源摘要卡片不再展开复杂持仓或管理控制；仓库尚无通用来源详情入口，因此未新增链接、占位路由或 Ticket 03 能力。

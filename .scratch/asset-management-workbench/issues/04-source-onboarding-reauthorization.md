# 04 — 独立来源接入与重新授权流程

**What to build:** 将新增来源和更换授权材料改为独立的多步骤页面流程。所有者依次选择来源、提供最小只读授权、查看权限与资产范围预览，再确认保存；已保存来源只显示安全授权摘要。

**Blocked by:** 03 — 资产来源列表、详情与生命周期.

**Status:** ready-for-agent

- [ ] 新增来源从资产来源工作区开始，完成“选择来源 → 填写授权 → 校验与预览 → 确认保存”的独立页面流程，不再使用承载完整业务流程的长弹窗。
- [ ] 各来源继续拒绝交易、划转、提现、未知或不完整权限；验证失败时不留下来源或凭证。
- [ ] 已保存来源详情只显示授权状态、校验时间与权限摘要；API Secret、OAuth Token、TOTP 等原文永不回显。
- [ ] 更换 API 凭证或重新授权必须重新提供授权材料，完成后保留既有来源身份、快照和卡片关联。

# 01 — 工作台应用壳与主导航

**What to build:** 将已认证个人资产看板放入资产管理工作台应用壳。所有者可通过桌面左侧导航和移动底部导航进入总览、资产来源、数据健康、设置与安全；锁定状态仍只显示登录入口和不含资产数据的页面。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 已认证所有者在桌面与手机宽度都能通过可访问的显式导航到达四个一级入口，Command-K 保持为补充快捷方式。
- [ ] 未认证、主动锁定、会话超时和浏览器会话结束时，不渲染工作台导航、资产、来源、快照或凭证信息。
- [ ] 已认证根入口进入总览；路由切换保留现有所有者会话与安全边界。
- [ ] 工作台继续复用既有 Vibe/Nothing 视觉语言，不引入第二套后台主题。
